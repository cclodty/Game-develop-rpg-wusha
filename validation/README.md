# 這份試玩包的驗證

- `release.json`：原始碼提交、套件版本、最新原生測試數與 Web 匯出 SHA-256。
- `native.log`：完整原生套件執行紀錄，當時介面套件為 214 項。
- `native-ui-final.log`：版面與正文修正後，介面套件的最後 254 項回歸。
- `web-result.json`：最終 Chromium 三出身、配招、存讀與實際卡戰的七組流程結果；內含對應匯出雜湊。
- `export.log`：Godot 4.6.3 Web 匯出紀錄。

原生各套件最新結果合計 **3,707 項**，以最後 254 項取代先前 214 項，不重複相加。瀏覽器測試透過真正滑鼠鍵盤操作，只讀取存檔核對結果。

瀏覽器報告中的錄影路徑指測試工作區，影片未加入下載包；下載頁提供本次實際瀏覽器截圖。序章與整章時長、理解程度及重玩意願仍待三位首次玩家實測。
