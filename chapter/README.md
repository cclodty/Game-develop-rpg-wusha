# 江湖未遠：渡口餘波

小說改編的獨立網頁試玩章節。玩家從逃亡後的落腳鎮開始，探索四處場景，與懷晴、杜蘅同行，以卡牌交手、分層研習，追查船行去向。

## 開始遊玩

1. 將 ZIP「全部解壓縮」。
2. 開啟資料夾內的 `index.html`，或在 Windows 雙擊 `Play-Windows.cmd`。
3. 建議使用桌面版 Chrome 或 Edge。不需 Godot、Python、帳號或網路。
4. 預設姓名陳天佑，可以修改。若想快速試戰鬥，依序完成「借一處屋簷」「同行有約」「院中試招」。

若瀏覽器限制本機檔案的存檔，遊戲會提醒；可從「存讀檔」下載 JSON 備份。開啟新版本或移動資料夾前也建議下載備份。瀏覽器網站資料不是雲端同步，清除資料會移除本機存檔。

開發者也可以在本資料夾執行 `python -m http.server 8073 --bind 127.0.0.1`，以固定的本機網址測試。

## 本版可以玩什麼

- 14 個事件，四張可點選探索的場景；點選標記查看事件，再選做法。方向鍵／WASD 移動標記，E 查看附近事件；這是點選場景原型，尚非具有碰撞與尋路的完整自由行走地圖。
- 人情、現場痕跡與交接紀錄三條交錯路徑；河倉可合法查貨、身法潛入或正面交戰。
- 按速度輪流行動的三人戰鬥，每人獨立十張牌、三真氣與跨回合的勢。同伴預設自行出牌，可接管；也能委託主角自動出牌。
- 三門入門武學各兩層。無倒數的排列推演、保底進度、每層最佳成績保存與自動套用；新牌要自行加入牌組。
- 自由手動存讀、活動自動保存、檔案匯出／匯入。戰鬥中換牌選擇、研習推演和現場勘查都能保存。
- 三種章末結果：有據追查、帶疑上路、行蹤外露。完成後仍可留鎮活動，下一區域尚未開放。

## 交手與日曆

- 點選手牌、點選敵人，再按普通施展／運勁。勢不足時仍可普通施展。保留一張牌後結束回合，下回合補至五張。
- 畫面上方是速度行動次序。按「暫停自動行動」可安心查看，角色下方可切換手動／自動。每場最多用藥一次，消耗一真氣，可替在場同伴用藥。
- 院內切磋完整顯示意圖。野外情報來自郎中、研習或伏哨便條；敵人的實力不隨角色變化。
- 每天早、午、晚三時段。活動耗時在開始前顯示，閱讀、步行與思考出牌不耗時。
- 舊棧道需在 D3 結束前完成，郎中需在 D4 午前拜訪。錯過後相關證據永久失去；交運副簿只提供去向，不補回同等證據。
- 普通戰鬥可撤退，保留已用時辰。河倉正面交戰即會曝光；撤退或落敗後原件被轉移。回客舍休養可消除傷勢，藥棚短工能補充盤纏。
- Ctrl/Cmd＋S 寫入手動欄位1；「存讀檔」還有其他欄位與備份下載。

## 試玩回饋

先看兩件事：有沒有一項發現讓你想繼續追查？有沒有一場交手讓你因情報、同伴或新招式而改變打法？

1–2 小時是完整章節的設計目標，本版尚未經真人時長與平衡驗收，沒有為達標加入強制等待。你可以分次試玩，進度會保存。

## 版本與來源

這是與舊七日旅程分開的網頁試玩入口，沒有改寫原 Godot 遊戲或它的存檔。`catalog.js` 由原專案的 `scripts/card_catalog.gd` 匯出；新的多人回合與事件模型在 `model.js`。正式整合回 Godot 尚未進行。

故事骨架來自小說寫作聊天紀錄，本工作區尚未取得完整原稿。地方支線、期限、杜蘅短期參戰與同伴武學配置是遊戲改編安排，尚待逐章核對。沒有提前揭露銀匙真正用途或命案完整真相。

四處場景中河倉與渡口共用同張生成背景的不同取景；人物暫用生成形象。資產來源見 `assets/provenance.json`；字型授權見 `assets/LICENSE-NOTO.txt`。

驗證紀錄見隨包 `validation/`。Chromium 已透過本機伺服器驗證三種結局與存讀檔；測試環境的管理政策禁止 file://，直接開啟檔案仍待玩家電腦確認。Windows／Edge 實機、Safari、真人戰鬥平衡與整章時長仍需試玩確認。
