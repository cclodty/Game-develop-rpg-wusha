# 首次玩家試玩流程：內功、留牌與七日養成

本文件是可執行的測試計畫，**不是已完成的真人驗收**。目前三個名額均待招募／待測，記錄見 [試玩清單](playtests/README.md)。本輪可先完成程式與可玩流程驗證；不得以開發者、自動腳本或虛構人物代替三位首次玩家。

## 對象、版本與準備

邀請三位未看過此原型、未讀企劃的成年自願玩家。至少一位不熟悉卡牌戰鬥、一位玩過卡牌；第三位不限經驗，以實際招募為準，不預先填寫經歷。每人獨立體驗，不讓前一人的答案影響下一人。

主持人先填版本提交／匯出檔 SHA-256、日期、平台、瀏覽器與輸入方式。確認本次執行的是內功與蓄勢 v3，port8072，旅程存檔 `run-martial-v3.json`、試招 `lab-martial-v3.json`，並以測試專用瀏覽器資料開始。卡牌 v2 與動作版的下載包及結果不可混入。先說明可以隨時停止；若錄音或錄影，取得當事人同意，未同意就以文字與時間戳記錄，不記真名或其他不必要的個資。

測前只問遊戲／卡牌經驗及輸入需求，不解釋六屬性、最佳答案、建議配牌或門派門檻。主持人可說：

> 「請按你自己的想法開始遊戲。你可以說出正在想什麼；也可以安靜玩。我想了解畫面是否說清楚，沒有標準的人格答案。卡住時可以告訴我。」

## 目標與計時定義

| 要回答的問題 | 證據 | 不算證據的情況 |
|---|---|---|
| 玩家為甚麼想進江湖 | 建角完成後，玩家以自己的話說出動機，指出至少一個選擇或回應如何支持它 | 只複述主持人剛說的角色設定；把任意選項當成唯一正確動機 |
| 能力是否可理解 | 玩家解釋自己較高的一項、另一項能力的實際用途，以及微調是否改變總點數 | 只認得名稱，或主持人先教完再答對 |
| 卡牌能否幫玩家讀懂對手 | 出牌前預測敵人本回合的行動與至少一張牌的作用，行動後能對照結果 | 只問「看得懂嗎」；用打贏作為理解的唯一指標 |
| 日程與成長取捨是否成立 | 能說出一次活動的時段、解鎖／精修收益與自己放棄的另一件事 | 主持人指定順序，或只看總通關速度 |
| 序章與全篇要多久 | 分開記錄序章、卡牌教學、正式行程、閱讀、停頓及技術中斷 | 以自動化秒數或刪除所有思考時間湊出目標 |

**序章目標為 6–8 分鐘。** 起點是第一段情境文字可閱讀，終點是看完六題回顧、完成微調並確認進入七日旅程。記錄完整牆鐘時間；下載／載入故障和外部中斷另列，保留原始總時間與扣除這些中斷後的時間。閱讀、思考、改選、正常回看都算體驗時間。主持人提出的測試問題另計，不塞進遊戲時長。

**首篇 30–60 分鐘也是目標，尚未達成人測驗收。** 起點同上，終點為第八日選擇去向並讀完收束。未完成、主動停止與技術阻塞都如實記錄，不換算成假想通關時間。

## 武學試招：本輪優先驗證

每位首次玩家先從「武學試招」選一套示範，查看三門內功和四類對手。先讓玩家自行閱讀、配招與交手，不先解釋最優牌序。三位安排不同起始示範，再由本人決定想換哪一套；記錄先後次序，避免把熟練後的成功誤記為首次理解。每套至少觀察一次連擊、重甲、蓄勢或反制帶來的取捨；沒有遇到的局面標「未觀察」。

- 開戰前問「你的內功怎樣得勢？花勢後有甚麼幫助？」記未提示原話。
- 有留牌機會時問「想留下甚麼，為甚麼？下一回合會怎樣補牌？」不能只記是否按過按鈕。
- 有運勁機會時觀察是否比較普通和運勁；戰後問「有沒有一次沒等到三勢就先花？你換到甚麼、放棄甚麼？」若沒有自然發生，標未觀察，不能替玩家造答案。
- 對同一對手至少一次自行調整牌組、內功或精修，記目的和實際改善；換對手後原打法的弱點也要記。
- 保存一次掠影步選牌中的局面，關閉並續玩試招；檢查選中手牌、留牌和資源是否符合預期，再確認正式旅程檔仍獨立。

普通戰鬥以2–4分鐘為初始目標，從起手可操作到勝敗結果，含思考、規則查閱和正常操作；主持人提問、外部中斷分列。勝率、牌序、自動策略速度都不能代替人的樂趣、理解或重玩意願。

## 正式旅程：分開記錄的後續測試

先試招者已經學過規則，不可再把其旅程首戰稱為零經驗理解。記錄是否先做過試招；若要測真正的新手旅程導入，另以未接觸版本的玩家進行，保留分開的結果。以下序章與七日流程仍需測，但不把三人試招自動算成三人完成首篇。

## 旅程執行順序

### 1. 情境建角：先觀察，後追問

讓玩家自選姓名與出身，完成兩次問答、泥車事件的三次選擇，以及歇腳回顧。不要指出屬性對照表或替玩家挑選「合理」答案。逐題記錄選擇、停頓、返回、對回應的反應，以及自行說出的疑惑。

六題完成、進入回顧時才問：

- 「你接下來想做甚麼？為甚麼？你覺得這個人為甚麼要去望溪鎮，哪段讓你有這個想法？」
- 「哪個選擇最像你想扮演的人？有哪個回應和你的意思不同？」
- 「現在這六項能力裡，選兩項說說你預期它們會改變甚麼。」
- 「若調整一點能力，哪些地方會變，哪些不會？」

記下原話，不先糾正。若玩家自發改點，觀察是否理解一次調整是移動一點、總和維持 30，以及最多兩點的調整額度。沒有改點不代表失敗；六題答案原樣保留也應能繼續。

### 2. 第一場卡牌戰鬥：檢查預測

讓玩家自行找到課程或練習。先記錄玩家有沒有主動查看敵意圖，不預先指向圖示。第一次出牌前，選一個不妨礙節奏的時刻問：

- 「你預期對手接著會做甚麼？你從哪裡看出來？」
- 「你想先用哪張牌？預期會改變甚麼？」

記錄預測，再讓玩家真的操作。之後問「結果跟你想的一樣嗎？哪個地方不同？」。觀察3點真氣、勢的跨回合保留／上限、手牌／棄牌、防護、換起手、留一張補至五張、普通／運勁與結束回合的理解；記錄誤點是否有清楚的無效原因，及重新思考後是否能改變策略。不要要求某一套最優解，不把輸掉一場當成可讀性不合格。理解風險後仍選進攻是策略選擇，不能記成誤讀。每場記錄活動與種子／起手，重試時區分理解改善和抽牌差異；只讀記錄，不注入狀態。

只有玩家主動求助或停滯超過 90 秒才逐級協助；先問他想完成甚麼，再提醒可用的區域，最後才說具體按法。每次記下等級與原因。接受具體操作提示後的成功，不計為「無提示理解」。

### 3. 七日安排：確認自由與代價

玩家至少完成一次新卡解鎖，打開免費「角色與配招」，並自行決定是否換入。若他沒有主動開啟，可用中性的任務「請看看能否調整接下來的打法」；記錄這是提示。不要替他指定卡片。

在他考慮下一個活動時問：「這個安排會花多少時間，得到甚麼？你因此暫時不做哪件事？」。若自然取得精修進度，再觀察是否理解按牌種精修、兩個複本同時生效、已解鎖穩定／專精方向可免費切換、首次悟性捷徑與一般成本；沒有遇到就標記「未觀察」，不要臨時注入資源。

讓玩家保存後關閉並重開，從原有斷點繼續。記錄是否找到繼續遊戲，以及日期、牌組、活動或戰場是否符合他的預期。主持人可記技術結果，不能拿這一步代替自動化存讀測試。

### 4. 收束與回訪

完成首篇或停止時詢問：

- 「你最後想去哪裡？這七天哪件事支持了這個決定？」
- 「再玩一次，你會換甚麼選擇或牌？為甚麼？」
- 「哪個時刻你不知道接下來能做甚麼？」
- 「若只改一件事，你最想改哪裡？」

不要只問喜不喜歡，也不預設玩家一定想重玩。若玩家主動選擇認輸或留鎮，記其理由；這是有效結局，並非必須修正的失敗。

## 記錄與判讀

使用 [空白模板](playtests/SESSION_TEMPLATE.md)。每個觀察標明「玩家原話」「主持人觀察」「待驗證推論」，不要把推論寫成玩家說過的話。截圖／錄影片段填本地檔案或經同意的連結；未錄製就留空。

三份完成後，只就這三人的結果寫小樣本結論，列出人數與個別差異，不聲稱統計代表性。以下用於決定修改，不能用來挑選或責怪玩家：

- 任何人遇到無法繼續、損壞存檔或重扣／重發獎勵：先修正阻塞，再測受影響流程。
- 兩人不能說明內功、留牌或普通／運勁取捨：優先改對應說明與預覽，再重測。
- 兩人對同一能力、牌面或敵意圖出現同一誤解：優先改文字、位置或回饋。
- 兩人不能以自己的選擇說明動機：回看選項與分支回應，勿只增加一段旁白宣告性格。
- 序章偏離 6–8 分鐘：先拆出閱讀、猶豫、返回及引導卡住的時間，不靠等待或刪選擇湊時長。
- 兩人能自行說出不同重玩方向：記下具體內容；若無人想重玩，也如實保留。

修改後只重測受影響部分；新版本、新受試者與重測紀錄分開標示。尚未進行的三位測試必須維持「待測」，不能因可玩程式完成而改成通過。
