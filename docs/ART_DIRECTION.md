# 《江湖未遠》美術規格 v0.1

本輪完成一套可直接進入遊戲的原創 Q 版武俠樣板：主角三種出身造型、六名主要人物、兩種普通敵人、一名考核者，以及望溪鎮、青篁溪谷、望風古道和標題主視覺。人物與場景均由 image_gen 生成，對話、標記和操作介面由 Godot 呈現，避免把文字烙在插畫上。

## 畫風與辨識

- **人物比例：**約 2.5 頭身，大頭與短手腳；面部輪廓圓潤，表情可愛，武器、髮飾與衣袖仍保持清楚剪影。主角三種出身沿用同一張臉與黑色束髮。
- **筆觸：**暖褐色細輪廓，水彩／水粉的明暗與紙感；環境細節集中在場景邊緣，活動區保持淺色、低干擾。
- **服裝：**交領、布腰帶、綁腿、軟靴與小型隨身工具，先用職業道具建立身分，再用顏色區分人物。首篇只使用劍類玩家兵器。
- **視角：**場景為俯視約四分之三角度，角色採容易閱讀的正面三分之四姿態。世界邏輯範圍為 1080×640，原圖等比例接近此範圍。
- **光線：**暖金晨光、玉綠植被和奶油白地面；重點場景維持人情與冒險感。

## 場景與構圖

三張遊玩場景均為 1629×965 RGB。碰撞由場景程式定義，插畫提供建築與地形識別；後續修圖需和碰撞區一起檢查。

- **`wangxi.png`／望溪鎮：**上方分布劍院、書院與渡雲會館，下方左右是藥鋪與驛站，中下方為戲台。中央廣場與左右縱向通路串連六名人物；南方中央保留抵達空間。避免再疊加整棟幾何屋頂，以免遮掉手繪建築。
- **`grove.png`／青篁溪谷：**左側溪流、竹林與石岸圍合場地；中右側明亮空地供走動與交戰。石祠和散落藥簍作為探索節點的視覺線索。
- **`ridge.png`／望風古道：**石階、木欄與松樹圍繞開闊古道；邊緣以峭壁和薄雲表現高度。戰鬥核心區保持寬闊，避免敵人預警被花草遮擋。
- **`title.png`／主視覺：**1586×992 RGB，左側淡色山霧留白供標題與選單；右側主角在山路眺望小鎮，桃花、晨光、青山與紅綢統一冒險基調。

## 戰鬥可讀性

玩家劍氣採暖金／米白，移動武功採玉青拖尾；敵人起手以珊瑚色區域加上形狀與動作提示呈現，避免只靠顏色識別。敵人影子與命中反饋應站在地面上，重要預警需在背景之上、角色之下，命中亮度短促而不遮住下一次動作。Q 版表情不取代清楚的攻擊範圍和足夠反應時間。

## 檔案來源與後續製作

`assets/generated/provenance.json` 記錄每個打包檔案的生成原始路徑、尺寸與 SHA-256。PNG 以原樣複製保留，初次及修正版本仍留在 `/workspace/generated_images`。既有原型人物圖只提供整體畫風參考，這一輪人物身分、配色安排、場景和主視覺重新生成；沒有把原型角色直接移入本作。

Scenario 僅列為未來素材管線候選。本次產出不需要 Scenario 帳號、點數或插件。後續擴充請把最終圖集、望溪場景與本文件一起作為參考，先檢查角色比例、工具剪影、留白與畫面閱讀，再納入遊戲。
