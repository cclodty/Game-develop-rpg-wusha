# 《江湖未遠》內功與蓄勢版美術與閱讀規格

第一章接續製作以 [第一章製作計劃書](CHAPTER_ONE_PLAN.md) 為基準；本輪閱讀更新已加入手寫楷體正文、獨立姓名飾框、編號選項與可試讀的速度設定。

最新方向：以插畫、半身表情與事件 CG 為核心的 GALGAME。已依概念圖建立可操作的 Godot 介面骨架，包含三人十二格表情、獨立背景與共用紙框，以及對話、功能頁和獨立存讀流程；入口為「視覺小說 · 介面試玩」。實作範圍與尚未接線的正式章節功能見 [GAL 介面骨架](GAL_INTERFACE_FRAMEWORK.md)。第一輪八張圖、二十種畫面仍作為 [視覺參考](ui-concepts/index.html)，不是所有概念均已完成遊戲邏輯；舊可行走地圖重設仍暫停。

2026-10-28 的 2D 打磨版加入天佑十二張、宋懷晴七張專屬招式插畫、短促飛牌與數值回饋、可調速度的劇情文字，以及卷首牌面圖鑑。使用 Godot 4.6.3，戰鬥閱讀重心仍是**對手意圖、內功、真氣與勢、出牌與留牌**。舊動作版完整美術規格見 [歷史文件](history/action-prototype/ART_DIRECTION.md)。

## 風格延續

**新繪人物與招式插畫以使用者於 2026-10-28 提供的渡口／綠衣劍客／藍衣少女參考圖為準。** 清秀漫畫五官、柔和細線、自然的插畫身形、淡彩水粉與暖紙感；以鼠尾草綠、灰藍、米白為主，動作由姿態與克制的筆觸表達。避免寫實皮膚、寫實肌肉、電影式硬光、濃重雕刻線和照片質感。人物專屬卡圖採用已確認配色：陳天佑為靛藍旅行服、短束髮與褐色行囊；宋懷晴保留綠衣、長髮飄帶。以人物身分與招式共同選圖，同招保持可辨識的劍勢、氣息或步法標記。

新 GAL 入口已使用獨立上半身立繪與四種表情，背景、人物與文字各自分層。以下全身比例規格描述保留的舊七日旅程：對話、建角與探索人物沿用修長全身圖集；戰鬥主角另用背影素材。既有全身圖集為 `characters-illustrated.png`。場景主角高 132、NPC 高 124 邏輯像素，腳底維持碰撞與互動定位。行走和呼吸以輕微旋轉／縮放呈現；新比例尚未製作逐格走路或揮劍動畫，不混用舊 Q 版動作格。舊 Q 版圖集與十二格動畫保留給歷史樣板。三種主角沿用同一張臉與黑色束髮，以郵袋、藥簍和戲班道具區分出身。交領、布腰帶、綁腿與軟靴形成服裝語言；重要場面保留停頓與情感，不以可愛表情沖淡人物選擇。

場景保留俯視偏斜視角；角色為正面三分之四姿態。世界可行走區仍為 1080×640，整體邏輯畫面 1440×900。城鎮與探索不因改用卡牌就失去可走動的空間。

## 情境建角

六題使用可正常閱讀的段落、角色肖像與既有場景作陪襯；文字區應有足夠實底，不能把正文直接壓在繁雜山路插畫上。泥車情境目前由文字、前後承接與選項回應呈現，沒有新增泥車插畫的完成承諾。

第一題與第六題依出身顯示對應熟人；結果頁列動機、六次選擇、能力來源與實際用途。微調操作應讓玩家看得出移出與移入的項目、剩餘可移點數、總和 30 及 2–8 範圍。數值說明是角色建立的功能，不寫入場景插畫。

人物動機不是成績。不要以大紅叉、優劣排名或「失敗人格」效果評斷合法回答。玩家回看、重選及讀長段落時可以停留，沒有逼迫閱讀速度的視覺倒數。

## 卡牌戰鬥構圖

`card_arena.gd` 使用新的修長全身肖像在固定位置展示主角與敵人，場景作較淡的背景。這版戰鬥不播放舊即時戰鬥的十二格動作循環，而以短移動、金色劍痕、受擊色閃及數字呈現已結算的效果；這些回饋不能另觸發傷害或改變抽牌。

正式 Godot 戰鬥現在使用完整 1440×900 畫面，下方每頁五張 202×210 的卡片；1080×640 緊湊版仍供舊測試及嵌入使用。抽牌超過五張時可翻頁，所有手牌仍可操作；不能因畫面只容五張就丟掉其餘牌。牌面依 `card-art.json` 選擇 `card-art-hero.png`（十二張）或 `card-art-huai.png`（七張）圖集，各卡擷取使用者的專屬插畫；原 PNG 不改圖，於執行時以 AtlasTexture 取樣。牌面順序為：

1. 招路、武學分類與真氣費用。
2. 招式名稱、精修方向與兵器需求。
3. 同一資料源生成的普通效果與運勁費用；完整條件可懸停，選中後另顯示可捲動的真實模型預覽。
4. 選中、留牌或換出標記；不能只用邊框顏色區分。

依使用者最新指示，所有文字統一為霞鶩文楷 TC Medium，舊 Noto 僅作缺字備援；手牌正文基準 14，名稱 18，圓形費用徽記 21；圖鑑卡片為 300×350，正文 19、名稱 25；這是目前版面數值，不代表首次玩家已確認足夠好讀。較長說明可在詳情／規則中查看，不能把被裁掉的關鍵條件當成省略。

敵意圖應在出牌前始終可讀，包含防守、總共幾段攻擊、每段傷害及反制。教頭半血階段於下一玩家回合才更新，不能在玩家出牌途中悄悄改掉承諾的意圖。真氣、勢、當輪產勢額度、氣血、防護、內功、待發伏針、反擊與本場用藥狀態和手牌分區，避免把敵人的防護誤看成自己的資源。

點牌只選取，普通施展與運勁各有清楚按鈕及耗勢說明；有勢時也不能自動運勁。零勢或費用不足應說明原因。留牌用「留一張」標記，並說明下輪補至五張；掠影步換牌階段顯示可選上限與確認／略過入口，不能讓玩家誤以為必須棄滿。內功規則和本回合是否已觸發應可查閱。

規則、牌堆與起手換牌可停下來看。沒有即時反應窗口，不沿用動作版地面紅圈作為必須躲避的訊號。舊版 J／Q／E／Space 戰鬥提示不能殘留在卡牌畫面。

## 本輪視覺驗證

需要以實際建角、三套試招配置、十張配招、普通／運勁、留牌、換牌中間狀態、五張及多頁手牌、長說明、多敵人與暫停／存讀畫面檢查：文字不裁切、焦點可見、牌堆不遮意圖、播放效果不蓋住結果。截圖和影片必須來自卡牌版實際執行，舊動作版或卡牌 v2 戰鬥圖不能放在新版 README 當作內功與蓄勢展示。

人工理解仍按 [PLAYTEST_PROTOCOL.md](PLAYTEST_PROTOCOL.md) 記錄；畫面正常渲染不等於敵意圖或卡牌已被首次玩家理解。

## 閱讀與操作回饋（2D 打磨版）

- 劇情對話速度：慢 22、適中 38、快 70 字／秒、即時；逗號及句末稍停。Enter／空白鍵第一次顯示全文，第二次繼續。選項在正文顯示完後開放，數字鍵在揭字中只顯示全文。
- 卷首、暫停選單提供閱讀與動態設定；劇情面板可直接切文字速度。設定獨立保存在 `user://presentation.cfg`，不改旅程或試招存檔。
- 建角問答及介面說明保持即時顯示；逐字效果套用於劇情對話，不強迫玩家慢讀操作資訊。
- 懸停牌面以 0.12 秒輕微放大；成功出牌以 0.38 秒飛牌與實際氣血／防護差值回饋。動畫不鎖住下一次合法操作，不再次結算牌效。
- 暫停和規則／牌堆面板會凍結戰鬥演出。讀檔恢復已結算狀態，不重播付款或傷害。簡化動態保留數值、關閉縮放與飛牌。

## 人物招式首批（2026-10-28）

天佑十二張樣板涵蓋現有試招牌池；懷晴七張涵蓋渡口章節目前已學招式，沒有因此解鎖新武功。缺少專屬插畫的角色用中性招路標記，不借用別人的人物插畫。人物顏色與姿態是美術樣板，不把「沉著／輕巧」自動加進 AI 傾向或人物能力。

地圖與場上人物的比例調整已暫停；現有場景仍屬比例測試，須另行重新考慮鏡頭、建築與道路尺度。對話下一步按 GALGAME 的半身立繪與表情處理，這次牌面製作沒有改動地圖或對話版型。

牌面、接線與驗證見 [人物招式牌面](CHARACTER_CARD_ART.md)。

## 第三人稱背影戰鬥樣板

依使用者提供的《活俠傳》構圖參考，Godot 戰鬥改為我方大型背影在左前景、敵人正面在右方較遠處。此為 2D 手繪圖層構圖，不涉及 3D 場景重建。主角背影高約 510 邏輯像素；單敵高 278、多敵高 236；角色大小只作用於戰鬥。視角背景採平視渡口空地，並非探索地圖替換。探索地圖的比例重設仍暫停。

我方資源置左下、敵方氣血及意圖跟隨各自站位、回合置頂；底部五張手牌與普通／運勁／留牌保留原本行為。點敵人身體可改目標，起手換牌、超過五張翻頁、掠影步換牌、藥物、規則、牌堆、暫停存檔均沿用原規則。離開戰鬥即還原既有探索畫面裁切，無改動地圖尺寸或碰撞。

本輪僅整合 Godot 樣板中的天佑背影；宋懷晴仍維持已確認綠衣配色與專屬卡圖。`chapter/` 三人隊伍的 HTML 戰鬥尚未套用背影版面。其他同伴需各自繪製獨立背影素材。出招回饋為單張立繪的短位移／色閃，不宣稱已完成逐格揮劍或背影表情。

驗證入口：`tests/test_rear_battle.gd` 檢查實際游標命中多敵人、意圖完整可讀、血條不壓字、離場後探索裁切還原；`WEIYUAN_REAR_BATTLE=1` 可用 `test_card_arena.gd` 重跑完整戰鬥控制與存讀快照檢查。
