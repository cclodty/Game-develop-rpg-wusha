# 《江湖未遠》內功與蓄勢企劃

本稿對應 `weiyuan-martial-core`，首篇仍為〈入山之前〉，序章為〈抵達之前〉。本輪完成十二張驗證牌、三門內功、武學試招與七日學武接線；完整兵器分類先建立藍圖，刀法、指爪、長兵、醫毒的正式牌池仍留待後續擴充。實測範圍見 [VALIDATION.md](VALIDATION.md)。

## 1. 核心體驗

原創 Q 版武俠養成 RPG。玩家從故事、師承、探索和修練取得武功，配置一種主兵器、一門主修內功與十張招式，因應敵人的公開意圖決定出手、留牌、蓄勢或運勁。

每輪都從獨立角色開始，沒有帳號永久屬性、通關後才能用的核心流派或付費抽卡。玩家累積的是對人物、牌序、取得路線與對手的理解。七日主線的核心武學可可靠取得；部分支線練法與遭遇變體在本輪開局決定，讓同一路線也有調整配招的理由。

| 範圍 | 本輪內容 |
|---|---|
| 平台 | Windows 鍵盤滑鼠優先，以桌面瀏覽器交付；Godot 4.6.3、Dialogue Manager 3.10.4 |
| 世界 | 可行走望溪鎮、青篁溪谷、望風古道，六名主要人物 |
| 主角 | 姓名、藥鋪／驛站／戲班三出身、六題情境建角 |
| 行程 | 七日、每日早午晚，共21時段；第八日選拔 |
| 武學驗證 | 十二牌、三內功、三套範例，連擊／重甲／蓄勢／反制四類試戰 |
| 模式 | 正式旅程循故事學武；武學試招提供完整驗證牌池，兩者獨立保存 |
| 時長目標 | 序章6–8分鐘、普通卡戰2–4分鐘、含序章的首篇30–60分鐘；均待真人驗收 |

## 2. 建角、出身與六能力

〈抵達之前〉沿用兩次旅前問答、三次雨前泥車協作與一次歇腳回顧。三出身各有熟人與回應，六題每題只增加一點能力，能力來源在結果頁公開。六項各從4起步，完成總和30；每項在三題可選，最多轉移兩點，最終範圍2–8。回看改選重新計算並清除微調，確認後不再改寫。序章不扣七日時段，沒有作答倒數。完整樣稿見 [PROLOGUE_SAMPLE.md](PROLOGUE_SAMPLE.md)。

| 能力 | 本輪用途 |
|---|---|
| 根骨 | 氣血上限 `52 + 根骨×3` |
| 力道 | 每回合第一張攻牌額外 `floor(力道/2)`，整張只加一次；不加反擊或延遲傷害 |
| 身法 | 每回合第一張提供防護的牌額外 `floor(身法/2)`；不放大內功防護回報 |
| 定力 | 每場一次換起手，上限 `1 + floor(定力/3)` 張 |
| 悟性 | ≥6 時首次解鎖精修只需1心得，通常及之後需2 |
| 機緣 | ≥6 時首次外出提前提供線索；不決定能否學到核心武學 |

出身仍決定物資與手藝便利：藥鋪24文／4藥、尋藥及學方多一藥；驛站40文／2藥、送信26文；戲班24文／2藥／見識1、小戲24文。其餘送信18文、小戲16文。新十二牌驗證池不設出身專屬卡；三出身共用五種初始牌各兩張，另已學收勢，初始主修歸元功、持劍。六能力與七日經歷共同形成差異，出身不鎖門派。

## 3. 內功與配招

主兵器為劍／刀／長兵／徒手；劍、刀、長兵牌必須符合裝備。拳掌、指爪、暗器、身法及輔修可通用。首輪十二牌中已有劍術、拳掌、暗器與通用技法；選刀或長兵不會憑空解鎖尚未製作的招式。

同時主修一門內功，開戰即生效，不佔牌組。十張牌、同名最多兩張，學會牌種後可自由配置兩個複本。鎮上無進行中活動時免費改兵器、內功、牌組與已解鎖精修練法；開始活動後全部鎖定。

三門內功分別透過防護吸傷、不同招路銜接、回合末留下真氣蓄勢；耗勢回報分別為補防護、抽牌和集中爆發。正常施展與運勁由玩家明確選擇。完整規則、十二牌、精修與武學分類見 [CARD_DESIGN.md](CARD_DESIGN.md)。

## 4. 七日成本與學武來源

走路、普通交談、看地圖／紀事、買藥與鎮上配招不耗時。正式活動先展示時段、費用、條件與本輪收益，接受後只扣一次。現實閱讀時間、卡戰回合數、暫停及重試不推動日期。外出來回、調查與戰鬥合計為同一活動。

| 活動 | 時段／費用 | 主要成果與條件 |
|---|---|---|
| 聽劍入門 | 2／12文，一次 | 武學+2、沈+2；破雲劍氣、照隙一劍、守中訣 |

| 街頭小戲 | 1，可重複 | 盤纏+16／戲班+24、蕭+1至3 |

核心取得路線是固定的。修橋與舊曲只是替代練法來源；若已學會該變體牌，額外獎勵改為1心得，活動預覽先明示。完成一次的事件不能重複領取。變體在本輪生成並保存，重讀、載入及同次戰敗重試不重抽。

三套範例的取得下限：守中牌組可由聽劍、練習、對練共5時段取得；行雲可由訪路、尋跡、問路、練習共8時段取得；歸元爆發在聽劍後即可組成。這只表示核心牌源與成本可達，不代表其餘七日已替玩家安排好。

精修只針對照隙一劍、掠影步、破雲劍氣，每種解鎖一次，兩個複本一起生效。通常2心得、悟性首次優惠1；解鎖後可在鎮上免費切兩種練法，試招亦可回到未精修基準。

## 5. 選拔、重試與模式隔離

照嶺需武學≥6、沈信任≥2，並考核勝出或完成未送達的信／守約護送之一。渡雲需見識≥6、陸信任≥2，並至少兩項不同探索，或考核勝出且至少一項探索。兩派皆合資格時自行選擇；留鎮續修一律可選，認輸也有完整收束。

活動出發鎖定兵器、內功、十張牌、精修、能力、藥額度、敵人變體與種子。重試保留配置、種子及已付時段；撤退保留成本、放棄未完成獎勵。用藥1真氣、每場最多一次，活動結算時扣實際用量。

武學試招直接選三套範例、四類敵人，可自訂配招與精修。能力固定各5、全十二牌與三內功可用、每場一份藥，不發正式旅程獎勵，也不扣七日行程。這是閱讀與比較規則的入口，不能把它當成角色已在故事裡學會所有武功。

正式存檔 `run-martial-v3.json`，試招 `lab-martial-v3.json`；舊 `run-cards-v2.json` 與 `run-v1.json` 保留。新交付使用8072與獨立 `weiyuan-martial-download`。後續門派修業、自由遊歷與江湖大事仍為擴充方向。

## 6. 驗收與限制

先檢查三套牌組在四類敵人前有可理解的優勢與調整理由，再擴張新兵器牌池。規則驗證涵蓋勢上限／當輪配額、支付先於回報、留牌補五、選牌中斷保存、反擊／延遲／死亡順序、零費循環與一次結算。

三名首次玩家的理解度、普通戰鬥2–4分鐘及整章30–60分鐘仍按 [PLAYTEST_PROTOCOL.md](PLAYTEST_PROTOCOL.md) 實測。模型可通關與自動化流程不能替代這些結果。歷史 v2 文件與下載見 [cards-v2](history/cards-v2/INDEX.md)。
