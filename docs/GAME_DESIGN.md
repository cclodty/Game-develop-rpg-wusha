# 《江湖未遠》遊戲企劃與首篇實作基準

工作名稱：《江湖未遠》。首篇：〈入山之前〉。本文件將已確認的方向落成可檢查的事件、時間成本與選拔條件；數值仍可依試玩調整。程式中的實際數值來源為 [`game_data.gd`](../scripts/game_data.gd) 與 [`run_state.gd`](../scripts/run_state.gd)。

## 1. 核心體驗與範圍

原創、Q 版、俯視角 2D 武俠養成 RPG。玩家自訂姓名和出身，在有限日數內安排練功、謀生、交友與探索，並親自移動、出劍、閃避。核心問題是：**你如何度過每一天，會決定自己成為怎樣的江湖人。**

故事輕鬆熱血，人物有自己的生活；選擇會影響武功、人際關係和去向，失利仍有完整收尾。武學屬中武尺度，有劍氣、身法、內功，人物與門派的不同主張是主要張力。世界與人物均為原創，不沿用既有武俠作品的角色、情節或美術。

首篇內容界線：

| 項目 | 本輪內容 |
|---|---|
| 地點 | 一座可行走的望溪鎮、青篁溪谷、望風古道 |
| 主要人物 | 沈照嶺、陸行雲、陶半夏、周望山、蕭小滿、林知微，共六人 |
| 出身 | 藥鋪學徒、驛站跑腿、戲班子弟，各有獨立開場與回應 |
| 成長 | 武學、見識、盤纏、回復藥、六人的信任、兩門可習武功 |
| 行程 | 七個準備日、每天早午晚三時段，第八日選拔 |
| 活動 | 16 種；部分可重複，獨立事件只發一次完成獎勵 |
| 戰鬥 | 主角單人、一種劍、普攻連段、閃避、兩個武功欄位 |
| 敵人 | 近戰攔路者、持長兵器者兩類普通敵人；一名考核教頭 |
| 結果 | 照嶺門、渡雲社、留鎮續修；兩派皆合資格時自選 |
| 劇本 | Dialogue Manager：64 個標題、424 條帶固定 ID 的對白／選項 |

主要操作對象是 Windows 電腦鍵盤滑鼠玩家；交付優先提供瀏覽器試玩，亦保留 Godot 專案與 Windows 匯出途徑。首篇目標為首次遊玩約 30–60 分鐘，**目前是設計目標，須以不熟悉遊戲的玩家實測；自動化通關不能證明實際遊玩時長。**

隊伍指揮、戀愛、門派經營、多兵器與首篇以後的可玩章節不在本輪範圍。

## 2. 世界、門派與出身

望溪鎮是旅人歇腳、戲班停演、藥材與書信轉運的山間聚落。兩派第八日舉行共同的入門選拔，卻各自判斷是否發出邀請。主角抵達時，準備時間剩下七天。

| 門派 | 武學與處世方式 | 首篇如何被玩家認識 |
|---|---|---|
| 照嶺門 `zhaoling` | 穩健劍術；專注、耐性、履行承諾 | 沈師傅的劍課與對練；一封終於送達的問候；完成護送 |
| 渡雲社 `duyun` | 靈活進退；觀察、應變、實際行動 | 陸行雲留下的古道步痕；修正地圖；把見聞帶去問路 |

兩派不是善惡陣營，也不封鎖彼此武功。先學破雲劍氣，仍可加入渡雲社；有兩份邀請也可選擇留鎮。

| 出身 ID | 初始盤纏／藥／見識 | 專屬便利 | 劇情辨識 |
|---|---|---|---|
| `herbalist` 藥鋪學徒 | 24 文／4 份／0 | 溪谷尋藥、藥鋪學方各多得一份藥 | 陶半夏代師父叮囑；學藥時能問保存方法 |
| `courier` 驛站跑腿 | 40 文／2 份／0 | 每次街巷送信賺 26 文，其他出身為 18 文 | 周望山核名冊；沈師傅提醒趕路的重心 |
| `performer` 戲班子弟 | 24 文／2 份／1 | 每次街頭小戲賺 24 文，其他出身為 16 文 | 靴子先「報名」；師傅談舞台轉身與實戰距離 |

三種出身均從武學 0、人物信任 0 開始。姓名可自訂，介面預設為「小行」；規則層遇到空白姓名時以「行路人」補上。出身不參與門派資格判定。

## 3. 七日行程與核心循環

**選擇今日目標 → 確認活動成本 → 遇見人物或挑戰 → 取得成果 → 調整下一步。**

總額為 21 個時段。城鎮走動、普通交談、問答、看地圖、整理紀事、買藥均不耗時；現實中的停留、閱讀與交戰不推動日程。每份回復藥售價 12 文。

活動確認頁顯示名稱、時段成本、金錢成本、條件和成果。接受後一次扣除全部時段與費用；一次外出的來回、探索、戰鬥共用同一筆成本。活動可跨早午晚和日界，不要求一定由早上開始；總剩餘時段不足時不可安排。

開始時保存未完成活動；成功後統一發獎，撤退保留已投入的時段與費用、放棄未完成獎勵。重試同一次遭遇不再收取時段或費用，回復該遭遇起始的藥物額度；成功或撤退才結算本次使用的回復藥。對話選項不另加隱藏的時間或好感懲罰。

玩家可以用完七日，也可在行程頁選擇收拾行囊、等候第八日。後者會先明示並確認放棄多少剩餘時段，避免為了到選拔而重複點休息。

|---|---|---|---|
| 聽劍入門 `sword_lesson` | 2、12 文 | 故事、一次 | 武學 +2、沈信任 +2、破雲劍氣 |
| 劍坪練習 `practice` | 1 | 戰鬥、可重複 | 武學 +1 |

全部一次性事件合計需要 22 時段，守約護送還需先用一時段送信，故一輪無法收完所有事件。兩派資格與兩門武功可在混合路線取得；取捨針對完整的人物故事與資源，不以禁止混修製造分流。

## 5. 可走通的準備路線

下列為編輯與測試參考，不要求玩家照表遊玩。NPC 普通訪談可穿插任何一天，且不耗時。表內活動均含回程，不額外增加日數。

| 日 | 勤學苦練路線 | 人情與奇遇路線 |
|---|---|---|
| 一 | 聽劍入門（2）＋劍坪練習（1） | 青篁訪路（2）＋街巷送信（1） |
| 二 | 同門對練（2）＋街巷送信（1） | 望風尋跡（3） |
| 三 | 未送達的信（2）＋劍坪練習（1） | 風亭問路（2）＋街頭小戲（1） |
| 四 | 溪谷尋藥（2）＋歇腳備藥（1） | 半支舊曲（2）＋歇腳備藥（1） |
| 五 | 藥鋪學方（2）＋街頭小戲（1） | 溪谷尋藥（2）＋歇腳備藥（1） |
| 六 | 青篁訪路（2）＋歇腳備藥（1） | 小橋補板（2）＋歇腳備藥（1） |
| 七 | 小橋補板（2）＋歇腳備藥（1） | 守約護送（3） |
| 結果重點 | 武學至少 6、沈信任至少 2、完成守約、劍氣；可獲照嶺邀請 | 見識至少 6、陸信任至少 2、多次探索、突進；可獲渡雲邀請 |

訓練路線先學會正面進攻，再由「替人送一封信」理解履約。社交路線先改地圖、讀足跡，再把見聞用在護送與照顧旁人。兩者的資源和招式不同，但皆有戰鬥、人物回應與結局。

規則測試另使用短路線驗證門檻：

- 照嶺：聽劍入門 → 劍坪練習四次 → 未送達的信，共 8 時段；即使考核認輸也符合條件。
- 渡雲：青篁訪路 → 望風尋跡 → 風亭問路，共 7 時段；即使考核認輸也符合條件。
- 混修：聽劍入門 → 劍坪練習三次 → 未送達的信 → 青篁訪路 → 望風尋跡 → 風亭問路，共 14 時段；兩門武功、兩派邀請皆可取得。

剩餘時段可補其他人物故事、藥物與盤纏，或明確放棄後直接等候考核。短路線是條件驗證，並非 30–60 分鐘的時長證據。

## 6. 行走與即時戰鬥

城鎮與外出地點可親自移動。城鎮任務以可見目標引導，探索有觀察點與攔路遭遇；完成觀察與交戰後才進入收尾。戰鬥場地獨立呈現，避免在閱讀或選單中受攻擊。

| 操作 | 輸入 |
|---|---|
| 移動 | WASD／方向鍵；城鎮可點地行走 |
| 互動 | F／Enter，或點人物接近互動 |
| 普攻連段 | 滑鼠左鍵／J |
| 閃避 | 空白鍵 |
| 正面劍氣 | Q，須習得破雲劍氣 |
| 位移突擊 | E，須習得掠影突進 |
| 回復藥 | R |
| 暫停／返回 | Esc |
| 存檔 | Ctrl+S |
| 閱讀／選項 | Enter 繼續，數字鍵選擇，也可用滑鼠 |

普攻有連段節奏；劍氣提供正面距離，突進把位移與出劍連在一起。體力與冷卻避免持續只按同一招。武學提升戰鬥能力，見識也有較小的戰鬥收益；資源與已學招式共同影響實際打法。

普通敵人與教頭以起手、地面範圍、蓄勢、收招表現攻擊。敵人標示使用朱紅／暖色危險語言，玩家技能偏金／青綠，範圍形狀亦不同。普通戰鬥不要求精準格擋或極短窗口；首篇沒有格擋必過門檻。

敗北後可原遭遇重試，也可撤退。考核可認輸，進入資格判定；不強迫反覆打贏才讓玩家看到故事收尾。是否好讀、命中是否有感、重試是否能改善表現，仍需真人操作評估。

## 7. 第八日考核與結果

選拔包含一場教頭切磋，並檢查七日內的成長與行動。考核勝負不是唯一分數；NPC 信任和不同探索、守約記錄都有明確用途。

| 去向 | 完整條件 |
|---|---|
| 照嶺門 | 武學 ≥6、沈照嶺信任 ≥2，且「切磋勝出」或「完成未送達的信／守約護送任一項」 |
| 渡雲社 | 見識 ≥6、陸行雲信任 ≥2，且「完成至少兩項不同探索」或「切磋勝出且完成至少一項探索」 |
| 留鎮續修 | 一律可選；兩派皆未邀請時仍可完成首篇 |

同時達標時顯示兩份邀請，由玩家選擇，不自動代選。兩派都未達標仍呈現七日的具體收穫；留鎮結局亦可主動選擇，文字不預設玩家一定戰敗。結局是首篇終點，後續生活用故事方向提示，不偽裝成已完成的無限續玩模式。

## 8. 劇本、美術與存讀約定

劇本在 [`first_week.dialogue`](../story/first_week.dialogue)，六人的普通訪談各有三個問題和退出選項，依出身及第 1–3／4–6／7 日調整回應。活動有開始或完整故事場景；需實際操作的活動另有成功收尾。詳見 [故事設定](STORY_BIBLE.md) 及 [寫作指南](WRITING_GUIDE.md)。

美術維持同一套 Q 版武俠：頭身比例約二至三頭身、圓潤五官、可辨識髮型與服裝輪廓、低飽和紙色／竹綠／靛青，少量朱紅與金作重點。場景採一致的俯視偏斜視角，戰鬥中央保持清晰，裝飾集中於邊緣。服裝與表情可愛，重要情節以動作和停頓保留重量。美術原件、授權與生成來源以素材文件為準；Scenario 仍為候選，執行遊戲不需要其帳號或額度。

角色已有獨立繪製的待機、行走、出招、閃避、受擊與倒地畫格，六名主要人物各有職業待機動作。世界移動與戰鬥狀態驅動畫格播放；攻擊命中仍以原有模擬時鐘判定，動畫不另發傷害。暫停時畫格凍結；戰鬥結果確定後播放短暫倒地演出，再顯示結果。造型使用三分之四視角與左右翻轉，八方向素材留待後續。標題的動畫圖鑑可逐格檢查，細節與來源見美術規格。

沿用 Godot 4.6.3 與 Dialogue Manager。即時戰鬥、行走與行程是新專案系統；不將舊對話原型冒充新玩法。新作使用自身應用名稱與 `user://run-v1.json`，保留舊原型及既有 GitHub 下載版。

存檔包含出身、姓名、日期時段、資源、信任、武功、完成事件、紀事、未完活動、對話位置、世界位置及戰鬥快照。讀取必須接續原活動，不再扣時；完成事件的獎勵只能結算一次。瀏覽器保存屬當前站點的瀏覽器儲存，不等同雲端帳號同步；實際啟動與存檔方式見交付說明。

## 9. 驗收與後續製作

| 驗收問題 | 本輪可驗證部分 | 還需的評估 |
|---|---|---|
| 三出身是否可完整遊玩 | 獨立開場、出身條件分支、共用活動與結局流程 | 盲測能否說出各自特色 |
| 兩條路是否能在七日內完成 | 行程計算、門檻測試、兩種武功、混修可行性 | 自由選擇是否自然引出不同路線 |
| 成本是否清楚 | 活動前確認、剩餘時段、日誌、提前選拔確認 | 初見玩家能否自行解釋取捨 |
| 戰鬥是否好讀 | 兩種敵人、教頭起手、暫停、重試、撤退流程 | 操作手感、提示可讀性、第二次表現 |
| 存讀是否可靠 | 日期、活動、關係、獎勵、防重複結算及戰鬥快照測試 | Windows／瀏覽器實機關閉重開 |
| 時長與重玩價值 | 完整首篇與另一條路線內容已提供 | 至少數名首次玩家實測 30–60 分鐘目標，記錄閱讀／探索／戰鬥耗時 |

製作順序仍是企劃定稿 → 玩法驗證 → 美術樣板 → 完整試玩打磨。當前交付將這四項串成可執行的首篇，供驗證方向；不以可啟動或自動測試通過等同完成商業品質驗收。

長期藍圖維持 **初入江湖 → 門派修業 → 自由遊歷 → 江湖大事中的選擇**。下一階段才設計兩派的共同課業與分歧、跨地區人物再會、重要事件的準備期限，以及留鎮路線如何銜接。上述後三階段尚未製作，本輪不追加隊伍、戀愛或經營系統。
