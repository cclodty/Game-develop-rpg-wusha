# 《江湖未遠》卡牌版遊戲企劃

工作名稱：《江湖未遠》。首篇：〈入山之前〉。本文件是 `weiyuan-card-prototype` 的實作基準；本輪先驗證**情境建角、七日養成與回合制卡牌**是否形成完整體驗。整合與驗證狀態見 [VALIDATION.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/VALIDATION.md)，舊動作版規格與結果另存於 [歷史目錄](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/history/action-prototype/INDEX.md)。

## 1. 定位與核心體驗

原創、Q 版、俯視角 2D 武俠養成 RPG。玩家先在旅途中的選擇建立人物，再親自走訪望溪鎮，在有限日數內安排練功、謀生、交友與探索。遭遇戰以回合制卡牌進行：看懂對手的意圖，從自己學過的招式中決定這一回合怎樣出手。

核心問題仍是：**你如何度過每一天，會決定自己成為怎樣的江湖人。** 建角不只替角色填數值；七日的成長也不只把傷害加高。玩家的出身、行事方式、學到的牌與最後帶進考核的十張牌，應能共同描述一個有選擇的江湖人。

故事輕鬆熱血、有生活味。武學屬中武尺度，包含劍氣、身法與內功；人物和門派的不同主張是主要衝突。失敗、撤退、認輸或未獲邀請都有可完成的故事收尾，不強迫戰勝才讓玩家看到結局。

| 範圍 | 本輪基準 |
|---|---|
| 平台 | Windows 鍵盤滑鼠優先，提供容易開啟的桌面瀏覽器試玩 |
| 世界 | 一座可行走城鎮、青篁溪谷與望風古道兩處探索地點 |
| 人物 | 六名主要 NPC、三種出身、一名考核教頭與兩類普通敵人 |
| 建角 | 六題情境選擇：兩問答、三次泥車事件處理、一次歇腳回顧 |
| 能力 | 根骨、力道、身法、定力、悟性、機緣；六題後總和 30 |
| 行程 | 七個準備日，每日早午晚三時段，共 21；第八日選拔 |
| 戰鬥 | 單人回合制卡牌；18 種牌、十張牌組、同種最多兩張、每回合抽五張／三點真氣 |
| 收束 | 照嶺門、渡雲社、留鎮續修；兩派皆合資格時由玩家決定 |
| 時長 | 序章 6–8 分鐘、完整首篇 30–60 分鐘，均為待真人驗證的目標 |

保留城鎮與探索的行走操作。即時普攻、閃避反應與兩個主動技能鍵屬歷史原型，不是本輪戰鬥規則。隊伍指揮、戀愛、門派經營、多兵器、隨機抽卡付費及後續可玩章節不納入首篇。

## 2. 序章〈抵達之前〉：先做選擇，再理解自己

自訂姓名與出身後，主角在前往望溪鎮的路上遇到陷入泥地的車。熟人先問離家的理由與行囊準備，接著由玩家分三步處理一件具體的小事，最後歇腳回望自己怎樣選擇。同行者會針對選擇回應，不能只用同一句「做得好」掩蓋分支。

| 題 | 場景職責 | 可選能力方向 |
|---|---|---|
| 1 | 問離家的動機：想證明、想發現、想找到歸屬 | 力道／悟性／定力 |
| 2 | 問行囊與旅途準備 | 根骨／身法／機緣 |
| 3 | 泥車剛陷住，先處理甚麼 | 力道／根骨／悟性 |
| 4 | 雨將至，如何找人配合 | 身法／定力／機緣 |
| 5 | 最後一段怎樣把車帶出來 | 根骨／定力／身法 |
| 6 | 歇腳時回看自己最在意的事 | 力道／悟性／機緣 |

六項能力各從 4 開始，每題只為所選方向加 1，總和由 24 變成 30；每項能力恰在三題可選，沒有只出現一次的稀有答案。完成後保留選擇摘要，說明能力的實際用途，允許最多兩點的微調：每次由一項移出 1 點、移入另一項，總和仍為 30，單項範圍 2–8。不想調整可直接接受。

能力高低不決定善惡，也不鎖定出身、門派或某條主線。第一題的動機是敘事回顧依據，不是把玩家固定成只能用某類牌的職業。詳稿、每個分支與回顧例子見 [PROLOGUE_SAMPLE.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/PROLOGUE_SAMPLE.md)。

| 能力／存檔 ID | 首篇可理解的用途 |
|---|---|
| 根骨 `constitution` | 氣血上限為 `52 + 根骨×3`，增加容錯 |
| 力道 `strength` | 每回合第一張攻擊牌，整張合計額外 `floor(力道÷2)` 傷害；不按每段或每個目標重複加 |
| 身法 `agility` | 每回合第一張提供防護的牌，額外 `floor(身法÷2)` 防護 |
| 定力 `resolve` | 每場一次調整起手牌，上限 `1 + floor(定力÷3)` 張 |
| 悟性 `aptitude` | ≥6 時，第一次精修只需 1 點精修進度；通常及其後每次需要 2 點 |
| 機緣 `fortune` | ≥6 時，第一次外出多一段實用提示；不直接完成目標、不多發獎勵、不擲成功率 |

悟性較低可用一次額外劍坪練習補足同一精修，機緣較低可依原有線索調查完成同一探索。兩者提供一次便利，不能演變成永久少一種牌或錯過整條路線。

## 3. 世界、出身與去向

望溪鎮是旅人歇腳、戲班停演、藥材與書信轉運的山間聚落。主角抵達時，距離兩派共同舉行的選拔只剩七日。兩派互相熟識，卻各有判斷弟子的方式。

| 門派 | 武學方向 | 看重的行動 |
|---|---|---|
| 照嶺門 `zhaoling` | 防護、穩定出劍、抓住破綻 | 耐性、專注、履行承諾 |
| 渡雲社 `duyun` | 抽牌、技法接續、靈活進退 | 觀察、應變、把見聞用出來 |

三種出身皆從武學 0、人物信任 0 開始；六項能力由同一套情境生成，不因出身預先分配額外能力點。

| 出身 | 初始資源與日常便利 | 起始已學會的出身牌 |
|---|---|---|
| 藥鋪學徒 `herbalist` | 24 文、4 份藥；尋藥與學方多一份藥 | 隨身藥敷 |
| 驛站跑腿 `courier` | 40 文、2 份藥；送信報酬 26 文而非 18 | 熟路快步 |
| 戲班子弟 `performer` | 24 文、2 份藥、見識 1；小戲報酬 24 文而非 16 | 亮相誘招 |

三種出身皆可透過相應活動學會另外兩種出身牌，亦可混學兩派招式。起始出牌配置統一為五種基本牌各兩張；出身牌已在牌庫中，玩家可在免費配招時自行換入。學會新牌不默默改動現有配置。

## 4. 七日循環、成本與存讀

**選擇目標 → 確認成本 → 走訪／探索／切磋 → 取得招式、資源與信任 → 配招或精修 → 決定明日安排。**

走路、普通交談、閱讀、查看地圖與紀事、買藥，以及在鎮上沒有進行中活動時配招都不耗時。現實中的思考時間、暫停與戰鬥回合數也不推動日程。正式活動在確認前顯示時段、盤纏、條件與成果；接受後一次扣除全部成本。活動可跨早午晚與日界，總剩餘時段不足時不可開始。

外出的往返、觀察與戰鬥算同一次活動。開始時鎖定牌組、精修狀態、六能力與戰鬥種子；重試同一遭遇保留這份出發配置，不再扣時，不以重試重抽種子。撤退保留已投入時段與費用，不領未完成獎勵。成功後統一結算，完成事件不能靠重讀對話或載入重複領取。

可以用完七日，也可主動收拾行囊等待選拔；後者須先明示並確認放棄的剩餘時段。第八日可認輸後查看資格，不強迫反覆戰勝。

卡牌版使用獨立的 `user://run-cards-v2.json`。保存六題與回顧、微調能力、已學牌、十張配置、精修牌種與進度、兩個一次性便利旗標，以及原有日期、活動、關係、獎勵、對話與位置。戰場另存精確抽牌堆／棄牌／除外牌、敵意圖與隨機狀態。壞快照應明示恢復失敗，不能悄悄重開戰鬥來假裝續讀。

## 5. 活動、解鎖與精修的取捨

信任通常最高 9；送信／小戲各自只能把對應人物信任提高至 3，不會降低較高的信任。「一次」指成功後不可再領該事件獎勵；未完成而撤退可再安排，但新出發重新付費。正式數值來源為 `game_data.gd`、`run_state.gd` 與 `card_catalog.gd`。

| 活動／ID | 時段／費用 | 原有成果／條件 | 新卡牌成果 |
|---|---|---|---|
| 聽劍入門 `sword_lesson` | 2／12 文 | 一次；武學 +2、沈 +2 | 破雲劍氣、守嶺式 |
| 劍坪練習 `practice` | 1 | 可重複；武學 +1 | 精修進度 +1 |
| 同門對練 `spar` | 2 | 可重複；武學 ≥3；武學 +2、沈 +1 | 首次學照隙一劍；每次精修進度 +2 |
| 街巷送信 `courier_work` | 1 | 可重複；盤纏 +18／驛站 +26、周 +1 | 首次學熟路快步 |
| 街頭小戲 `stage_work` | 1 | 可重複；盤纏 +16／戲班 +24、蕭 +1 | 首次學亮相誘招 |
| 溪谷尋藥 `herb_errand` | 2 | 一次；藥 +3、見識 +1、陶 +2、盤纏 +8；藥鋪另 +1 藥 | 資源支援，沒有額外卡牌 |
| 青篁訪路 `grove_survey` | 2 | 一次；見識 +2、林 +1 | 山溪回響 |
| 望風尋跡 `ridge_tracks` | 3 | 一次；見識 +2、陸 +2 | 掠影突進 |
| 守約護送 `escort_promise` | 3 | 一次；先送過信；盤纏 +32、武學 +1、見識 +1、周 +2、守約紀錄 | 資源與錄取依據，沒有額外卡牌 |
| 小橋補板 `bridge_repair` | 2／12 文 | 一次；見識 +1、林 +2、陸 +1 | 護橋之約 |
| 未送達的信 `missing_letter` | 2 | 一次；見識 +1、周 +2、沈 +1、守約紀錄 | 一諾凝神 |
| 半支舊曲 `old_ballad` | 2 | 一次；見識 +2、蕭 +2 | 舊曲回氣 |
| 風亭問路 `hermit_visit` | 2 | 一次；見識 ≥3；見識 +2、武學 +1、陸 +2 | 流雲切、雙燕回鋒 |
| 藥鋪學方 `medicine_lesson` | 2 | 一次；藥 +3、見識 +1、陶 +1；藥鋪另 +1 藥 | 隨身藥敷 |
| 檐下讀記 `meditate` | 1 | 可重複至見識 6；見識 +1 | 沒有額外卡牌 |
| 歇腳備藥 `rest` | 1 | 可重複；藥 +1 | 沒有額外卡牌 |

介面的「練習心得」即下文的精修進度。

**精修按牌種進行，一種只修一次，該種兩張複本一起提高。** 通常消耗 2 點精修進度；悟性 ≥6 的首次只消耗 1，使用後記錄旗標，其後仍需 2。精修本身不另扣時段，取得進度需要安排練習／對練。因此「多學一種新招」「把常帶的招式練熟」「攢盤纏與藥」會爭用七日行程。

已學牌的重複來源不再給新的複本，也不自動精修。同種最多兩張是配牌限制，不是可反覆刷取的物品數量。完整牌表見 [CARD_DESIGN.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/CARD_DESIGN.md)。

所有一次性事件合計 22 時段，護送還要先花一時段送信，一輪無法看完全部事件。不同探索只計成功的尋藥、訪路、尋跡、護送；重讀或重複同一探索不會增加不同探索數。

## 6. 兩條可以混合的準備路線

以下是驗證用的 21 時段例子，不是強制攻略；三種出身皆可採用。普通人物交談可以免費穿插。確定性驗證只證明成本與條件可達，不能證明玩家自然會找到或覺得有趣。

| 日 | 勤學苦練 | 人情與奇遇 |
|---|---|---|
| 一 | 聽劍入門（2）＋劍坪練習（1） | 青篁訪路（2）＋街巷送信（1） |
| 二 | 同門對練（2）＋街巷送信（1） | 望風尋跡（3） |
| 三 | 未送達的信（2）＋劍坪練習（1） | 風亭問路（2）＋街頭小戲（1） |
| 四 | 溪谷尋藥（2）＋歇腳備藥（1） | 半支舊曲（2）＋歇腳備藥（1） |
| 五 | 藥鋪學方（2）＋街頭小戲（1） | 溪谷尋藥（2）＋歇腳備藥（1） |
| 六 | 青篁訪路（2）＋歇腳備藥（1） | 小橋補板（2）＋歇腳備藥（1） |
| 七 | 小橋補板（2）＋歇腳備藥（1） | 守約護送（3） |

勤學路線取得三張照嶺牌、4 點精修進度，以及守約證據；可精修兩個牌種，或保留進度後另行考慮。其打法著重防護、下一張攻擊與抓破綻。人情路線取得三張渡雲牌與多種事件牌，見識與陸信任足夠，但此例沒有練習進度；若想精修，必須換掉部分休息或支線。其打法著重技法接續、抽牌與靈活配置。

兩路都不是純劇情或純戰鬥，也不鎖死門派。起始與已學牌超過十張時，玩家必須挑選：新牌不保證每次都比基本牌更適合自己的配置。不要把「收集全部」誤當唯一成功標準。

## 7. 卡牌遭遇與第八日選拔

每回合展示敵人接下來的意圖，玩家以三點真氣處理五張手牌。思考沒有反應倒數。選牌、指定目標、施放技法或保留防護後，主動結束回合；手牌棄掉、敵人依已展示意圖行動，下一己方回合重置防護與真氣並抽牌。抽牌堆空時洗回棄牌；標示「本場除外」的牌不參與該場再抽，避免零費資源無限循環。

戰鬥細節、敵人招式與可重現種子規則以 [CARD_DESIGN.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/CARD_DESIGN.md) 為準。教學應讓玩家實際比較攻擊／防護選擇，不能只有一串需要按「下一步」的說明。

| 去向 | 條件，與建角出身無關 |
|---|---|
| 照嶺門 | 武學 ≥6、沈信任 ≥2，且「考核勝出」或「完成未送達的信／守約護送之一」 |
| 渡雲社 | 見識 ≥6、陸信任 ≥2，且「完成至少兩項不同探索」或「考核勝出且至少一項探索」 |
| 留鎮續修 | 一律可選；無邀請仍有完整收束 |

同時達標顯示兩份邀請，不替玩家選門派。認輸會結算選拔結果；有邀請仍可留鎮。後續「門派修業 → 自由遊歷 → 江湖大事」保留為藍圖，不宣稱第九日已可繼續遊玩。

## 8. 製作、驗證與邊界

沿用 Godot 4.6.3、Dialogue Manager、Q 版角色與可走動場景。六題情境由明確資料與建角流程控制；既有七日劇本延續人物關係，改寫即時戰鬥說明。卡牌模型與視覺分離，卡牌文字依實際效果生成，避免文件與畫面各有一套數值。

先完成可玩縱向流程，再用新測試驗證：六題每個屬性三次機會、總點數與微調、18 牌／十張配牌、精修與一次便利、回合／意圖／洗牌與快照、三出身七日與結局、存讀不重扣或重發。舊版 8,013 項測試通過只屬動作版歷史；本輪結果另行記錄。

真人測試按 [PLAYTEST_PROTOCOL.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/PLAYTEST_PROTOCOL.md) 執行，已有三份空白紀錄，均待招募／待測。需要回答的不是只有「打不打得贏」，還包括玩家能否說明動機、能力、敵意圖、時間取捨與想重玩的另一種選擇。6–8／30–60 分鐘不能由腳本跑完而宣告達成。

卡牌版發佈預定使用獨立的 `weiyuan-cards-download`，新包名 `jianghu-weiyuan-cards-web.zip`／`jianghu-weiyuan-cards-source.zip`，本機網址 8071。舊 `weiyuan-download`、8070 與動作版存檔保留；本文件不代表新包已發布。
