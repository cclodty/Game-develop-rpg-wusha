# 《江湖未遠》卡牌原型美術與閱讀規格

本輪沿用統一 Q 版武俠角色、場景與字體，將戰鬥閱讀重心改為**對手意圖、手牌、費用與結果**。本輪沒有新增十八張專屬卡圖，也沒有宣稱重畫一套動畫；先用既有插畫與 Godot 排版驗證玩法。舊動作版完整美術規格見 [歷史文件](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/history/action-prototype/ART_DIRECTION.md)。

## 風格延續

人物約 2.5 頭身，暖褐細輪廓、水彩／水粉筆觸、圓潤五官。三種主角沿用同一張臉與黑色束髮，以郵袋、藥簍和戲班道具區分出身。交領、布腰帶、綁腿與軟靴形成服裝語言；重要場面保留停頓與情感，不以可愛表情沖淡人物選擇。

場景保留俯視偏斜視角；角色為正面三分之四姿態。世界可行走區仍為 1080×640，整體邏輯畫面 1440×900。城鎮與探索不因改用卡牌就失去可走動的空間。

| 用途 | 本輪介面色 | 閱讀原則 |
|---|---|---|
| 紙面 | `#F8F1DF`／`#FCF7E9` | 為正文與數字提供穩定淺底 |
| 深墨 | `#293F39` | 主要文字、角色與回合資訊 |
| 玉綠 | `#376C5C` | 技法、確認與主要操作 |
| 暖金 | `#BC9457` | 選取、焦點與劍痕 |
| 暖赭 | `#A55F4C` | 攻擊牌類型；同時保留「攻擊」文字 |
| 次要文字 | `#65746A` | 來源、說明及低優先資訊 |

顏色不能單獨承擔資訊。攻擊／技法有文字；敵人顯示傷害、段數或防護；選中卡牌有邊框與狀態字。費用不足、目標無效、活動進行中不能配招等原因要用文字說清楚。

## 情境建角

六題使用可正常閱讀的段落、角色肖像與既有場景作陪襯；文字區應有足夠實底，不能把正文直接壓在繁雜山路插畫上。泥車情境目前由文字、前後承接與選項回應呈現，沒有新增泥車插畫的完成承諾。

第一題與第六題依出身顯示對應熟人；結果頁列動機、六次選擇、能力來源與實際用途。微調操作應讓玩家看得出移出與移入的項目、剩餘可移點數、總和 30 及 2–8 範圍。數值說明是角色建立的功能，不寫入場景插畫。

人物動機不是成績。不要以大紅叉、優劣排名或「失敗人格」效果評斷合法回答。玩家回看、重選及讀長段落時可以停留，沒有逼迫閱讀速度的視覺倒數。

## 卡牌戰鬥構圖

`card_arena.gd` 與 `card_ui.gd` 使用既有肖像在固定位置展示主角與敵人，場景作較淡的背景。這版戰鬥不播放舊即時戰鬥的十二格動作循環，而以短移動、金色劍痕、受擊色閃及數字呈現已結算的效果；這些回饋不能另觸發傷害或改變抽牌。

在 1080×640 戰鬥區內，下方每頁五張約 202×205 的卡片。抽牌超過五張時可翻頁，所有手牌仍可操作；不能因畫面只容五張就丟掉其餘牌。牌頭沿用 35×46 的 Q 版肖像，沒有另稱其為新繪製的專屬卡圖。牌面順序為：

1. 類型與真氣費用。
2. 招式名稱與是否精修。
3. 由實際效果資料生成的精簡說明；完整條件與本回合模型預覽可懸停查看。
4. 來源分類或選中狀態。

字體沿用 JianghuSans／JianghuSerif（Noto），卡面正文基準 15，名稱 18，費用 23；這是目前版面數值，不代表首次玩家已確認足夠好讀。較長說明可在詳情／規則中查看，不能把被裁掉的關鍵條件當成省略。

敵意圖應在出牌前始終可讀，包含防守、總共幾段攻擊及每段傷害。虛弱或教頭半血變化後，畫面必須同步更新；不能要求玩家猜測隱藏乘數。真氣、氣血、防護、牌堆與已用藥狀態和手牌分區，避免把敵人的防護誤看成自己的資源。

規則、牌堆與起手換牌可停下來看。沒有即時反應窗口，不沿用動作版地面紅圈作為必須躲避的訊號。舊版 J／Q／E／Space 戰鬥提示不能殘留在卡牌畫面。

## 既有素材與來源

| 素材 | 目前用途 |
|---|---|
| `assets/generated/characters.png` | 十二個角色的透明肖像圖集；三主角、六 NPC、三敵人模板 |
| `wangxi.png`／`grove.png`／`ridge.png` | 可走動地點及戰鬥背景 |
| `title.png` | 標題主視覺；文字仍由遊戲繪製 |
| `assets/generated/animation/` 與 `inbetweens/` | 已有十二格素材庫，供世界行走／NPC 與獨立圖鑑沿用；不是本輪卡牌戰鬥的完成證據 |

角色圖集為 1448×1086、4×3 格；場景為 1629×965，標題為 1586×992。透明取樣與場景碰撞保留現有規則，任何後續修改都要連同完整剪影、腳底定位和可通行區域檢查。

原圖來源、尺寸與 SHA-256 保存在 `assets/generated/provenance.json`；動畫來源另見 `animation/hero_provenance.json`、`foes_provenance.json` 及 `inbetweens/` 的三份來源記錄。原有十四張動畫 PNG、42 組／504 姿勢是既有資產；不把它們計成新繪製的卡牌圖。細節見 [動畫歷史介面](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/ANIMATION_CONTRACT.md)。

Scenario 仍只是候選素材工具。本輪沒有安裝其插件，也不依賴帳號、點數或付費服務。後續若製作專屬卡圖，先完成一張攻擊、一張技法與一個敵意圖的樣板，確認裁切、留白與閱讀，再擴充全套。

## 本輪視覺驗證

需要以實際建角、十張配招、五張手牌、長說明、多敵人與暫停／存讀畫面檢查：文字不裁切、焦點可見、牌堆不遮意圖、播放效果不蓋住結果。截圖和影片必須來自卡牌版實際執行，舊動作版戰鬥圖不能放在新版 README 當作新玩法展示。

人工理解仍按 [PLAYTEST_PROTOCOL.md](https://github.com/cclodty/Game-develop-rpg-wusha/blob/fc1e2ae957349caafec2e4163cf5737320584e5e/docs/PLAYTEST_PROTOCOL.md) 記錄；畫面正常渲染不等於敵意圖或卡牌已被首次玩家理解。
