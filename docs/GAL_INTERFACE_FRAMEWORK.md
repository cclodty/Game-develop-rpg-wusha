# GALGAME 介面骨架

2026-10-28：依使用者最新方向，以大量場景插畫、人物半身表情與事件演出作為主要呈現方式；先建立可重用素材與介面，再擴充故事。不再以完成 2.5D／3D 自由行走作為此路線的前提。

Godot 原卷首新增「視覺小說 · 介面試玩」，亦可直接開啟 `res://scenes/gal_preview.tscn`。這是可操作的介面樣板：有自己的演出進度及保存空間；舊七日旅程、武學試招及 HTML 小說章節仍保留。

第一章的統一方向、製作批次與系統差異見 [第一章製作計劃書](CHAPTER_ONE_PLAN.md)。目前優先按 Goal 完成介面還原與實機驗收；正式開場事件後續另接，不以介面導航選項代替劇情分支。

## 已接通的介面流程

- 卷首 → 姓名輸入 → 客舍對話 → 選項 → 場景頁。
- 對話支援首次點擊補齊文字、再次繼續；選項要等本句顯示完成。Enter／Space 繼續、數字鍵選項、H 隱藏文字、Esc 開關選單；自動播放遇選項會停下。
- 正文改採霞鶩文楷 TC Medium 手寫楷體 32 字級、行距加 12；姓名採獨立深綠金邊飾框，選項另有編號與「請選擇回應」提示，懸停和鍵盤焦點可見。
- 對話列直接切換慢／適中／快／即時；設定頁可用相同字體試讀、重播，以及調整全文顯示後的自動停留 1–6 秒。字速及停留時間保存到獨立的 `presentation.cfg`，不寫入劇情進度。
- 回看、設定與存讀頁會保留底下的對話實例、逐字顯示與自動播放進度。隱藏文字後點擊場景可恢復；背景按鈕在彈出頁期間停用，避免滑鼠及鍵盤穿透。
- 人物頁可切三人與四種表情；主角十張配招以五乘二排列，可從已學招式分頁選取替換，使用既有規則驗證兵器與每招最多兩張。同伴頁只顯示現有專屬插畫並停用替換，不會改動主角牌組；杜蘅缺圖明示待補。圖鑑以並排雙卡比較天佑與懷晴的同招插畫。
- 行囊按概念圖改為左側旅行袋、中間四乘三物品格、右側大圖與詳情；可依全部／藥物／要物／雜物分類，選擇後保留鍵盤焦點。手札可開啟實際對話回看；不可在此使用的物品顯示停用操作。
- 手札改為書冊分頁，可依實際已讀紀錄篩選、選條目並閱讀片段；沒有把閱讀狀態冒充任務完成。區域頁以場景示意圖提供四地點入口，沒有新增自由行走地圖或碰撞。
- 研習包含三種武學、兩層選取與可操作的排列推演。各武學／層獨立保存最佳成績，較差重試不覆蓋；已有成績時再次研習自動沿用。
- 勘查逐項閱讀，全部看完才能整理筆記；筆記加入回看資料。
- 試招使用現有 CardArena 模型，支援四類對手、真實出牌、暫停與勝敗結果。此處仍是單人戰鬥，與小說版三人模型的正式合併待做。
- 章末頁提供演出配置，沒有將其當作已完成的故事結局。
- 自動欄位與三個手動欄位使用 `user://gal-interface-v1-0.json` 至 `-3.json`；覆蓋手動欄位先在遊戲內確認，載入壞檔不修改目前狀態。試招中先完成交手再保存演出，不假裝保存了未支援的中途戰鬥。

## 後續接線邊界

本輪搭的是介面及演出骨架，並非重新實作完整小說章節。既有文字是遊戲改編稿，不宣稱為小說原文。示範頁可直接瀏覽條目，沒有套用正式章節的事件解鎖、歷史日曆、期限、時段成本及獎勵。研習排列演示不會向原旅程發牌；場景切換不會推進明代大事件。

仍需補齊：完整情境建角、正式章節模型接線、三人戰鬥、各場景專用背景、正式物品庫存與消耗、同伴獨立牌組編輯、更多事件 CG、對白表情標記、已讀快進、存檔實際快照與時間。舊地圖重設仍暫停；本輪只演示 GAL 場景式入口。

### 固定驗收順序

1. 實機擷取 1440×900 與 960×600；親自開啟截圖，檢查框線、圖像邊界、對齊、字體、文字裁切和焦點。不能只檢查檔案存在。
2. 操作開關、返回、再次開啟、分類、選取及切換；檢查一般、懸停、焦點、選取、停用狀態。依頁面增加空內容、長字串及較多內容案例。
3. 執行相關原生檢查；交付匯出版時再以真正滑鼠鍵盤操作匯出版，不注入遊戲狀態。保存同步須等到 IndexedDB 完成後才判定，不能把舊讀值當遊戲失敗。
4. 發現問題先修正，再重新驗證受影響頁面、更新截圖及構建雜湊；已知問題不留待使用者發現。
5. 更新本文件、章節計劃及驗證紀錄，交付實機圖與清楚的未接入範圍。無法執行的檢查只能標示「尚未驗證」。

本批次自查曾發現並修正：配招底部說明越框、招式列半張裁切、長篇回看太貼近捲動條、長姓名壓到盤纏區、同伴預覽可誤改主角牌組、功能頁底下露出場景控制列。最終驗證結果與逐頁檢視紀錄見 `artifacts/gal-goal/validation.json`；截圖分別存於 `final/` 及 `browser/`。標有 `fixture-` 的原生截圖為邊界測試資料，不是正式劇情。


最終驗證：126 項原生 GAL 檢查通過；同一匯出版通過 16 項跨頁滑鼠／鍵盤驗證及八組閱讀、存讀回歸，沒有瀏覽器或引擎錯誤。另以滑鼠滾輪確認長篇回看及圖鑑運勁詳情可閱讀後續內容；853 個 GAL 漢字均有文楷字形。原生環境仍有軟體顯示無法設定 V-Sync、第三方測試場景 UID 改用有效路徑載入兩項非阻斷警告，詳見原始日誌。

| 手札與章末 | 真實事件紀錄和已讀對話；三種章末結果保留實際證據、曝光及失敗後果 |
| 保存 | 三個手動欄、活動自動保存、上一份備份、JSON 匯出／匯入；閱讀位置與歷史另存於包裝資料，故事模型不混入播放設定 |

`jianghu-gal-web-v1:*` 與舊版本分開；`jianghu-gal-web-reading-v1` 僅保存閱讀偏好。使用者可主動匯入舊章節 JSON；沒有閱讀資料時回到保存場景，不捏造已讀紀錄。保存故事不重設字速，開關介面不扣時間、不發獎。

本輪使用既有原圖，SVG 在執行時依圖集格線裁切，加入明確的 clipPath，避免較寬的顯示框露出鄰格。沒有修改原 PNG。全篇文字和數字使用 WenKai，沒有從系統明體取代。勘查、背包與卡牌名稱皆為真正可選文字或按鈕。
