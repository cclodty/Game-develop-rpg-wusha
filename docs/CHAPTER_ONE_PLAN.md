# 江湖未遠第一章製作計劃書

版本 1.5 · 2026-10-29 · 工作篇名〈渡口餘波〉

第一章以手繪 GALGAME 作為演出基礎，結合區域內自由探索、人物互動、分層研習與卡牌戰鬥。先把可重用的場景、立繪、文字框和功能頁做穩，再以事件 CG 增加重要場面的份量。畫面品質與閱讀節奏優先，不以完成 2.5D 或 3D 行走為前提。

此處的「第一章」指遊戲的第一個完整可玩章節，沿用目前〈渡口餘波〉的逃亡後落腳與水路追查，並不宣稱等同小說正文第一章。正式開場與小說章節的對應列入下一批核稿工作。

本文件供使用者與後續製作助理共同接續工作。標為「已確認」的是對話中明確定下的方向；事件數量、平衡數值與素材預算屬本版製作基準，可以依試玩修改，但須同步更新本文件。

## 三 第一章要讓玩家經歷什麼

玩家帶著傷勢、銀匙與未解的命案，先找到一處可休息的屋簷。在懷晴與杜蘅的協助下，他逐漸取得行動能力，也能決定先練武、幫人、查訪或探索。最後找到可信的下游去向；查得多、錯過線索或留下曝光，會帶來不同的出發條件。

本章的情感重點是從被追趕轉為能作選擇，以及與懷晴建立具體的合作默契。杜蘅有自己的判斷與本地責任。人物反應應回應玩家做過的事，不能只用好感數字替代交流。

故事骨架沿用[事件表的來源界線](NOVEL_FIRST_REGION_EVENTS.md)：裴守成託付銀匙、作證後遭滅口、懷晴護人逃亡、杜蘅協助與傷者線索、烏篷行相關往來。工作區改編稿不能代替小說正文。正式文本前須核對人物稱呼、傷勢、先後次序、地理與絕對日期；本章不提前揭露銀匙用途、幕後真相或後期重大秘密，也不在章末直接替懷晴洗清嫌疑。

一般路線內容預算沿用約 90–115 分鐘，精簡約 60–75 分鐘，屬待真人試玩的目標。以新發現、人物回應與打法變化支撐時長，不靠重複戰鬥或等待湊數。

## 四 章節流程與事件範圍

### 開場與角色建立

正式新遊戲包含改名及問題環節。目前 GAL 樣板有改名及起步配置回看，沒有情境問答，尚不能視為完成。問題數量先以六題為製作提案，內容圍繞受託、求援、風險與處事方式，結果頁說清楚起步傾向及可調項目。問題不作人格優劣評分，也不改寫必須成立的小說前情。具體能力映射待核稿後設計，暫不照搬七日旅程的三種出身。

接著以少量文字、聲音與事件 CG 交代抵達原因，再進客舍。追殺作為已發生的故事壓力，不設閱讀倒數或必死反應測驗。首次引導只教會繼續對話、作選擇、查看行囊和回到場景，其他系統在需要時介紹。

### 事件安排

E00–E02 為短導入，其餘依條件開放。下表是正式章節的製作目標，完整耗時與分支見事件表。

| 事件 | 演出與玩家行動 | 核心成果或代價 |
|---|---|---|
| E00 雨後抵達 | 前情、改名後銜接客舍 | 知道逃亡原因與眼前目標 |
| E01 借一處屋簷 | 杜蘅療傷、約定聯絡方式 | 安全據點、日期與傷者去向線索 |
| E02 同行有約 | 與懷晴商量，決定同行及控制方式 | 開放隊伍、同伴自動與接管說明 |
| E03 院中試招 | 可認輸切磋、首次研習 | 體驗真氣與勢；開放三門入門練法 |
| E04 藥棚的短差 | 一次具體委託，後續可做安全短工 | 藥物與盤纏來源，避免零資金卡死 |
| E05 船工的人情 | 交涉、繞行或交手取回工具 | 信任、帳簿與合法進倉路線 |
| E06 退潮後的舊棧道 | 勘查封籤與拖痕 | 限時原始證據及身法筆記；過期不能補回 |
| E07 渡口帳簿 | 信任查閱，或支付查抄費 | 船行與下游停靠站，提供可靠去向 |
| E08 即將離開的郎中 | 交談與觀摩 | 限時證詞、敵人徵兆情報 |
| E09 草棚外的伏哨 | 可遠觀、繞行或挑戰 | 便條與河倉情報；不是必打關卡 |
| E10 河倉留痕 | 合法查貨、身法潛入或正面交手 | 交接紀錄；武力造成曝光，失敗可能失去原件 |
| E11 檐下再議 | 回客舍與懷晴交換實際見聞 | 回應玩家的方法、失敗與合作關係 |
| E12 散失的證據 | 查公開交運副簿 | 補追查方向，不補原始證據或限定收穫 |
| E13 去向已明 | 整理出行，決定離開或繼續逗留 | 三種章末條件；不自動傳送到下一區 |

最短主線可由安頓後取得 E07 的去向，再會合進 E13；E05 人情或 E04 短工提供取得帳簿的途徑。完整取證路線則交錯 E06、E08、E10。研習與可選戰鬥不得變成每條路線的強制門檻。

### 三種章末條件

| 結果 | 條件與承接 |
|---|---|
| 有據追查 | E07 帳簿及 E10 交接紀錄齊備，沒有河倉武力曝光；下一區可從核對接件人切入 |
| 帶疑上路 | 有可靠去向但缺關鍵證據，沒有曝光；下一區先尋人，缺失證據仍然缺失 |
| 行蹤外露 | E10 正面開戰且已有可靠去向，不論勝負；船行已有警戒，後續入口改變 |

先判曝光，再判證據。個別線索、同伴知情與關係另行保存，不能只留一個結局名稱。第一章只交付章末回顧與承接資料，第二區域另做。

## 五 系統規則與版本差異

### 探索與時間

正式章節以四個場景入口為基本單位：落腳街區、渡口市集、河岸舊道、河倉；客舍、藥棚、院落可作子場景。用場景圖、可點選人物與熱點移動，不開新的行走碰撞工程。

沿用一日早、午、晚三時段。閱讀、選單、普通場景查看和思考出牌不耗時；開始活動前顯示成本與期限。承諾活動時鎖定成本，結算或撤退時只推進一次日期；讀檔不能重扣或免掉這筆成本。原型的扣時實作與事件表用語須在移植時統一，不能同時在開始和結束各扣一次。

E06 須在 D3 晚結束前完成；E08 須在 D4 午開始前完成。恰好按時完成先結算活動，再觸發封路或離開。沒有整章總倒數，免費休養和替代調查路線持續存在。明代大事件使用獨立絕對日期觸發；本章先保留介面並測地方期限，不捏造開場年號或把重大歷史事件硬塞進幾日內。

### 卡牌與同伴

第一章目標是主角、懷晴、杜蘅三人按速度輪流行動，每人有自己的手牌、真氣與勢。同伴預設自動，玩家能在其行動前暫停、查看及接管；自動動作也須經同一套合法出牌判斷。

沿用現有原型的起步數值：每人十張牌、同名最多兩張、每回合三真氣、補至五張、回合末可留一張；勢上限三、每回合獲得最多二，可跨回合保留。普通施展與運勁分開，額外手牌可翻頁，不因畫面容不下而刪牌。這些是可測試的平衡基準，並非小說中的武功定論。

主角可編完整十張；同伴暫採七張核心加三個可調位，只能選各自已學的招式。初期四類交手為切磋、攔路者、伏哨、河倉守衛。切磋完整顯示意圖；野外從徵兆、情報與研習逐步辨明意圖。不得直接把舊單人樣板的全情報顯示當成所有野外敵人的規則。

現狀：Godot GAL 使用既有單人 `CardArena`；三人模型在 `chapter/model.js`。下一階段應把章節規則移植為獨立 Godot 模型，以相同輸入比較狀態結果，再接背影介面。不要在畫面腳本內另寫一套不同的傷害、期限或獎勵算法。

### 研習與成長

本章先做劍術、身法、內功各兩層。首次該層進無倒數推演，保存 0–4 的最佳成績，往後自動套用；玩家可選重試，較差結果不覆蓋最佳紀錄。學會的牌加入武學庫，由玩家自行換入。

現有 HTML 原型以每次保底二點加本次成績，第一、二層門檻暫為八與十點；這些數值屬平衡基準。GAL 樣板目前只有排列與最佳成績演示，沒有正式章節的進度或時間收益。移植時統一層號：正式資料用第一、二層，介面樣板現有 `0/1` 索引不得直接當成正式存檔層號。

### 失敗與保存

切磋可認輸；普通戰鬥可撤退。失敗的傷勢、盤纏或證據代價在活動前說明，主線保留較差結果的接續途徑。懷晴分頭辦事有位置與回返時間，不瞬間召回，也不會知道玩家尚未告知的情報。

正式章節須保存事件階段、已承諾成本、方法、獎勵結算標記、日期、同伴位置與知情範圍、證據來源、曝光、研習成績及戰鬥隨機狀態。畫面播放與動畫不直接發獎。場景、戰鬥、推演中途讀檔均應回到同一個決策點。

新正式章節使用有版本的獨立存檔；目前 `gal-interface-v1-*` 只是介面演出存檔，不能假裝包含完整章節狀態。舊旅程和試招存檔繼續保留。閱讀設定 `presentation.cfg` 與劇情存檔分開，換存檔不重設字速。

## 六 美術與介面的共用規格

### 人物與場景

以 [對話實機畫面](images/gal-dialogue.png)、[對話選項](images/gal-choices.png) 和原始 [概念圖](ui-concepts/images/dialogue.png) 共同作對照：概念圖供材質與飾框方向，已確認的實機人物比例與朝向優先。

立繪採自然修長的上半身，三人各有平靜、微笑、擔憂、堅定四種基礎表情。對話同框使用 520×780 的取樣框，按角色眼睛高度微調垂直位置。主角固定左側、視線偏向玩家；同伴在右。切換表情不裁切透明邊界重算尺寸，不因說話權改變攝影距離。特殊演出可以另設構圖，但須有明確場景理由。

主角使用 `hero-player.png`；`hero.png` 為保留的側望版本。現行引擎翻轉主角使身體朝內，背帶也會翻轉；正式 CG 或需要嚴格服裝連續性的畫面，應補專用朝向原畫。不要為修一張圖擅自更換整個角色的髮型、衣紋與配色。

場景保留淡彩筆觸、溫暖木色和自然光。事件 CG 用於危險、發現及人物關係變化，不把每一句普通交談都畫成新 CG。靜態畫面先用克制淡入、輕微推鏡及聲音形成節奏；嘴型、骨架動畫與完整配音不列為首章必要條件。

### 文字與選擇

使用者已否定明體的辦公文件感；正文、姓名與選項應有原概念圖的手寫楷書氣息。使用者已接受霞鶩文楷 TC Medium 1.530，並要求所有文字套用此字體；後續以此為統一基準，不把生成圖的文字誤認為已知字型。

| 元件 | 本輪落地規格 |
|---|---|
| 正文 | 霞鶩文楷 TC Medium 手寫楷體，邏輯字級 32，額外行距 12；長段可捲動，正文不烘焙進圖片 |
| 姓名 | 手寫楷體字級 31，深玉綠底、雙金邊與兩側紋飾；框寬隨姓名調整 |
| 選項 | 獨立切角雙線框、手寫楷體字級 27、數字編號、上方「請選擇回應」提示；滑鼠與鍵盤焦點皆明確 |
| 功能文字 | 所有按鈕、選單、工具提示、卡牌與數字同樣使用霞鶩文楷 TC Medium，不能自行改回黑體；缺字才走備援字型 |
| 字速 | 慢 22、適中 38、快 70 字／秒及即時全文；標點另有停頓，對話列可直接切換 |
| 自動播放 | 本句顯示完後另等 1–6 秒，預設 1.8 秒；有選項時永久停下等待玩家 |
| 設定頁 | 同字體試讀、重播試讀、字速、句間停留、減少動態；閱讀設定持久保存 |

點擊未播完的正文先顯示全文，下一次才前進。選單暫停底下的逐字與自動播放，關閉後從原處恢復。選項必須等本句顯示完才可選；不可因切換字速、重播試讀或按 Enter 而偷偷提交第一個選項。普通分支不設選擇倒數。

正式腳本將選項分為語氣、情報、活動承諾和路線四類。只對已知且會付成本的選項顯示時段、銀兩或條件；鎖定時說明原因，不洩露尚未發現的劇情結果。現行 GAL 末句的兩個選項只是介面導航，不能當作 E02 的完整分支已完成。

真人試玩至少記錄兩件事：玩家想繼續追查的發現，以及因情報、同伴或招式而改變打法的一次交手。自動測試只證明規則與操作成立，不替代節奏、吸引力與難度評價。
