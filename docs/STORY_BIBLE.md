# 《江湖未遠》故事設定：情境建角與七日卡牌

本稿用於卡牌原型；舊即時動作版的故事設定快照見 [歷史文件](history/action-prototype/STORY_BIBLE.md)。本輪延續六人的關係與七日事件，新增旅前選擇與泥車共同經歷；完整序章文字見 [PROLOGUE_SAMPLE.md](PROLOGUE_SAMPLE.md)。

## 故事主張

江湖不是離日常最遠的地方，而是你開始為自己的選擇負責的地方。七日的價值不只在最後拿到哪一塊門牌，也在你多看清了誰、把哪一件事情做完、學會什麼時候出手與收手。

語氣輕鬆、熱血、有生活味。幽默來自人物的小習慣與互相熟悉，情感來自具體事情：一封回信、一只修好的木偶、一段可以走的橋板。不以角色被羞辱製造笑點，不用重大身世之謎取代首篇的行動。

主角是一個正準備開始的人，可以機靈、謹慎或直率，但不預設天命、血仇、祕笈繼承者身分。三個出身是學過的手藝與看世界的角度，不是道德或門派選項。對話中的「你」在介面使用玩家姓名；敘事中的「你」維持第二人稱。

## 世界與尺度

望溪鎮位於山路交會處。藥鋪、驛站、戲班、書攤與修習劍坪共同構成日常生活；山外的世界先透過來信、舊曲、地圖與旅人的話進入畫面。時間沒有持續流逝的倒數，只有玩家正式安排的七日行程。

| 地點 ID | 氛圍與敘事用途 | 首篇行動 |
|---|---|---|
| `wangxi` 望溪鎮 | 有炊煙與人聲的山間聚落；每個人都不是只在等主角 | 訪談、修習、送信、戲台、小橋、選拔 |
| `grove` 青篁溪谷 | 青竹、苔石、採藥小徑；需要看細處 | 藥草辨認、失落藥籃、舊地圖核對、攔路遭遇 |
| `ridge` 望風古道 | 迎風石階與不完整步痕；需要按今天的情況改路 | 讀足跡、學突進、護送藥箱、攔路遭遇 |

武學可形成可見劍氣與短距離身法，但不移山填海。普通敵人會在回合開始顯示進攻或防守意圖；教頭的任務是看清候選人的準備，不是要置人於死地。玩家有時間思考，敘事不要求在閱讀中突然按鍵閃避。沒有沿用舊原型人物或治水主線。

照嶺門與渡雲社互相熟識，也互相補足。沈照嶺相信先將一件事做穩；陸行雲先問是否還有另一條路。他們可為告示該釘三枚還是四枚釘子拌嘴，卻都願意給主角認真的答覆。門派不是善惡二選一。

| 人物／畫像 ID | 想要什麼、怕什麼 | 說話與動作 | 首篇轉折 |
|---|---|---|---|
| 沈照嶺 `shen` | 想教出懂得收劍的人；擔心弟子根基不穩，也曾太快把不合意視作不努力 | 短句，先問具體問題；修木劍、重繫鞋帶，不突然講大段人生格言 | 舊弟子的信讓他先問近況，沒有立即寫教訓；主角可用履約得到信任 |
| 陸行雲 `lu` | 想有人能帶回新的看法；不願把自己的舊路變成別人的唯一答案 | 輕巧玩笑，常借飯錢自嘲；說不知道就一起去看 | 主角改踩古道步痕，他認可變通；教法是觀察出口，不是閉眼求快 |

| 蕭小滿 `xiao` | 想把戲唱好，也想留一點空間給尚未寫好的生活；擔心讓人失望 | 愛抬一句再輕輕接住；捲紅綢、敲平台角釘子、替木偶說話 | 承認舊曲有多種可能；台上扮英雄與台下照看人並不衝突 |
| 林知微 `lin` | 想把地圖畫對、留下可用的記錄；怕弄錯，容易把求證拖成反覆重畫 | 溫和而具體，願意承認空白；量橋板、擦錯線，笑點來自過分認真 | 溪谷回報讓他擦掉漂亮卻錯的直線；補板讓紙上之路變成腳下之路 |

六人互相認識：周與蕭因戲裡的飯錢梗拌嘴，陶與周共用藥材與竹籃往來，林的地圖連接陶的採藥路，陸會在修橋時先讓挑藥籃的人過。這些連結用短場景表現，避免六個互不相干的任務櫃台。

考核教頭、陪練、挑籃者、觀眾孩子、寄信舊弟子、未見面的隱士都是功能性背景角色，不擴張成第七名主要可訪談 NPC。後續若要加入持續人物，需另外討論內容預算。

## 情境建角與共通抵達

第一幕不是填完六項數字才出發，而是先問「這一趟想為自己做甚麼」。三種出身的熟人開場不同，六個選擇卻共用一件人人都能理解的小事：驛車陷在雨前的泥坡，大家要把人和貨一起送到地方。

| 階段 | 玩家選擇 | 敘事必須留下的東西 |
|---|---|---|
| 離家問答 `reason` | 做成難事／看懂世界／找到歸屬 | 主角自己的動機，沒有預定天命或門派 |
| 行囊問答 `packing` | 備好吃食／整理鞋帶與物件／帶信並認識同行人 | 照顧自己、行動便利或願意開口的第一步 |
| 泥車初步 `mud` | 卸貨／扶車讓人下來／觀察支點 | 不是一招解決所有事；下一題承接實際做法 |
| 雨前協作 `rain` | 取石墊路／統一口令／向後車借力 | 讓自己的方法與別人的幫忙接起來 |
| 最後一程 `last_load` | 陪慢行者搬貨／核對人貨借物／替大家試出乾路 | 脫困後也要收尾，成功不能留下別人的麻煩 |
| 歇腳回顧 `reflection` | 記住出力／記住理解／記住同行 | 不把玩家貼成固定性格，讓他說明自己想帶走甚麼 |

| 出身 | 旅前的問候 | 歇腳時接住故事的人 | 七日中的延續 |
|---|---|---|---|
| 藥鋪學徒 | 師父重貼藥瓶標記，這次不替鋪子送貨 | 陶半夏先看手、再看藥瓶，讓主角歇一歇 | 藥鋪回應、學方、照顧同行人的手藝 |
| 驛站跑腿 | 前輩交回空信袋，這次沒有人催回執 | 周望山先放下信袋，問自己的故事 | 送信、回覆、護送與自己的行程 |
| 戲班子弟 | 前輩收好戲服，這次沒有寫好的台詞 | 蕭小滿讓主角說自己的第一折 | 戲台、舊曲、照看台前與台後的人 |

六題中的十八種回答均有獨立回應。泥車第四、五題還會接上上一題的做法，不只是把相同場景換個屬性獎勵。回顧列出完整六次選擇及能力來源；玩家可調整最多兩點，不改變整體點數。每個方向都能成立，沒有隱藏的「最像好人」選項。

第一題留下 `creation_motivation`（`prove`／`discover`／`belong`）；泥車三題留下 `creation_approach`（`unload`／`brace`／`observe`）、`creation_support`（`fetch`／`steady`／`ask`）與 `creation_finish`（`carry`／`sequence`／`path`）。後續人物可以呼應這些具體選擇，但不能聲稱知道未被傳達的每段內心獨白。回應應承認玩家的做法，不用同一個標籤反覆評斷人格。

建角完成才正式進入七日；序章不先偷扣準備時段。本輪以 `arrival_morning` 銜接：熟人早餐、晨街、沈師傅的木牌與陸行雲送來的早餐，再確認七日規則回到鎮上。舊 `intro_<origin>`／`arrival` 只保留相容與固定 ID，不是本輪主入口；不重新演一次離家，也不假裝主角尚未見過歇腳的熟人。兩派都可詢問；學到不同派的牌不代表已經選好歸屬。

## 七日情緒與對話節奏

第 1–3 日先建立人物：劍拿哪一把、信要怎麼核、地圖哪裡仍是空的。第 4–6 日談練習與新見聞，也讓戲班開始把主角的經歷想成「七日小俠」。第 7 日承認選拔臨近，給出具體提醒，不靠製造恐慌催玩家。

這些日數問候在每個 `npc_<id>` 開頭使用讀取條件；不表示人物知道玩家尚未完成的任務。普通訪談是可返回的問題選單：每人三個主題，加一個進入可安排活動的出口。玩家可反覆閱讀，不扣時、不發獎。

正式故事場景盡量以一個具體動作開場，以主角理解的改變或能帶走的東西收尾。選項用於表達理解，沒有把某一句漂亮話設成隱藏的唯一錄取答案。

## 事件流程、伏筆與收束

| 事件 | 開始的疑問 | 玩家投入 | 收束與玩法關聯 |
|---|---|---|---|
| 聽劍入門 | 劍氣是不是只要更用力？ | 談握劍或呼吸，接受兩時段課程 | 鬆緊、呼吸與時機；學會破雲劍氣與守嶺式 |
| 劍坪練習／對練 | 多打一下是否總比較好？ | 看敵意圖、安排攻防、主動結束回合 | 把留有餘地化為實際防護；武學與練習心得成長 |
| 街巷送信 | 小消息值得專程跑嗎？ | 送信、聽回覆 | 竹籃修好的消息今天就用得上；工錢與履約前置 |
| 街頭小戲 | 沒站在台中央也算演好戲嗎？ | 道具、觀眾與開演準備 | 沒有人拔錯劍，幕後工作被看見；工錢 |
| 溪谷尋藥 | 一趟收穫是不是越多越好？ | 認草、尋籃、處理回程風險 | 藥根與位置留給下一人；藥物、見識與陶的信任 |
| 青篁訪路 | 一條畫得很漂亮的線就可靠嗎？ | 親看水痕、竹刻與岔路 | 林擦掉錯線；見識與一次不同探索 |
| 望風尋跡 | 把前人的腳印踩準就是輕功嗎？ | 讀今天的風、草與落腳處 | 主角主動換步；學會掠影突進牌，記下「到時再看」 |
| 守約護送 | 自己先到是否等於帶大家抵達？ | 先送過信，再護送藥箱與順路小匣 | 人貨平安，木偶回到戲班；守約證明與資源 |
| 小橋補板 | 再量一次就等於開始做了嗎？ | 花費木料、實際修補與試走 | 藥籃穩穩過橋，沒有盛大致謝；林與陸的信任 |
| 未送達的信 | 「木劍先生」究竟是誰？ | 問舊稱、核對戲班記錄，信不拆封 | 沈師傅收到舊弟子問候，先想問近況；守約紀錄 |
| 半支舊曲 | 三種唱法，誰一定是對的？ | 聽出留白、同行者，或承認還不懂 | 保留其他版本，不假稱發現絕世祕笈；見識 |
| 風亭問路 | 向高手請教是否只要帶敬仰？ | 帶已有見聞去找陸，隱士卻去賣菜了 | 藉歪凳找重心，替人理好鞋帶菜筐；見識、武學、信任 |
| 藥鋪學方 | 大問題說不清時該怎麼問？ | 分辨、配份量、包紮與保存 | 把問題縮成「能否站穩」；藥物與見識 |
| 檐下讀記 | 如何把「大有收穫」寫得真實？ | 寫一件具體小事，刪去空泛詞 | 見識入門，達到上限後需出門尋新知 |
| 歇腳備藥 | 大俠可不可以休息？ | 休息與整理行囊 | 休息不是失去志氣；補藥、準備下一段 |

主線關聯是「把看見的事用出來」，不是所有事件暗中服從同一陰謀。信與護送提供照嶺重視的守約證據，探索與對古道的理解提供渡雲重視的見聞。學武、人情、資源互相連通。

## 考核與三個結局

`exam_intro` 以鎮上的日常持續開場，提醒考核是七日的回望。根據武學／見識給鼓勵，不因角色未練滿而出言羞辱。教頭切磋可重試、可認輸。是否錄取由中央規則檢查行動與信任，劇本不私自改門檻。

| 結局 | 情感落點 | 代表物 | 後續方向 |
|---|---|---|---|
| `ending_zhaoling` | 紀律是一扇可以繼續問問題的門 | 木製門牌 | 門派修業；尚未製作 |
| `ending_duyun` | 不把今天的答案當作明日唯一的路 | 青繩結、修正地圖 | 同行與自由遊歷；尚未製作 |
| `ending_stay` | 未進山也不抹去走過的路 | 驛站的一張床、收好的紅綢 | 留鎮續修的另一種起點；尚未製作 |

留鎮結局兼容「未達門檻」與「收到邀請但自行留下」，不寫死為考核失敗；兩派結局不暗示另一派不如自己。結尾明言首篇落幕，保留方向但不承諾已可繼續操作第九日。

## 創作與實作邊界

台詞、旁白、選項均有固定唯一 ID。條件只讀 `story_context()` 明示提供的姓名、出身、日數、剩餘時段、武學、見識、已學劍氣／身法、去向及建角回應標記，不讀未宣告的任務旗標。玩家是否拿到招式卡、練習心得、門派或金錢都由活動結算處理，不由台詞選項暗中寫入。序章選擇也由建角狀態層更新，敘事資料本身不另存一份能力。

前置場景不能說任務已完成；需要戰鬥或跑點的事件，只有 `complete_<id>` 才描述回程與收穫。這能讓退出、戰敗、讀檔重試都保留正確敘事順序。故事型活動使用完整 `activity_<id>`，讀到結束才完成其已確認的時段安排。

後續章節可延伸寄信舊弟子、陶半夏想看的海、林未畫完的圖、戲班下一站，但本輪不揭示大型陰謀、不新增主角血統設定，也不把提示寫成已存在的下一章任務。

## 卡牌的敘事語言

「招式」是學過的本事，「配招」是這次準備怎樣使用。不要讓居民把世界說成紙牌桌，也不要避開玩家操作需要的明確說明：老師可以說先看對手架勢，介面則明確顯示攻擊數值、防護、真氣與回合。

照嶺的入門課先給劍氣與守勢，同門對練再學照隙；渡雲先由古道身法入門，帶著見聞問路後再學流雲與回鋒。這個次序讓進階招式有相應的人物往來，並保留混修自由。修橋、送信與舊曲帶來的卡，應回應玩家做過的事，不把每場日常都寫成偶然撿到絕世祕笈。

悟性高的首次精修便利不代表老師較偏愛；機緣高的外出提示來自看見／問到一個具體線索，不表示其他玩家注定錯過。低值有相同牌池與事件出口。真人是否理解這些關聯，依 [試玩流程](PLAYTEST_PROTOCOL.md) 觀察，不能用劇本可編譯代替。
