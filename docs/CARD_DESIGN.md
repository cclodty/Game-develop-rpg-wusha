# 首篇卡牌設計與數值

本稿對應 `weiyuan-card-prototype` 的 [`card_catalog.gd`](../scripts/card_catalog.gd)、[`card_battle.gd`](../scripts/card_battle.gd) 及 [`run_state.gd`](../scripts/run_state.gd)。這是本輪可玩驗證的數值基準，後續平衡應修改單一資料來源後同步此稿；不以模型能通關宣稱真人已覺得好玩。整體範圍見 [GAME_DESIGN.md](GAME_DESIGN.md)。

## 牌庫、配招與精修

牌池共 **18 種**：5 基本、6 門派、3 出身、4 事件。起始牌組是五種基本牌各兩張，共十張；出身只決定一種額外「已學會」的牌，不自動換進起手配置。其他出身可由活動補學，兩派牌可混合。

上場固定十張，每種最多兩張，只能放已學牌。在鎮上、沒有進行中活動時，配牌免費，不耗時段。學新牌、精修或讀取存檔不得偷偷把玩家的配置改成推薦牌組。活動接受後鎖定牌組、六能力、精修與抽牌種子，不能在戰敗後進選單改牌卻仍聲稱是同一次重試。

練習心得 `mastery` 由劍坪練習 +1、同門對練 +2 取得。每牌種可精修一次，通常需 2 點心得；悟性 ≥6 的第一次只需 1，使用後保存旗標，其後仍需 2。精修提高下表數值，不改卡 ID、費用或十張上限，兩個複本同時改善。悟性較低多安排一次練習即可補足首次差額。

## 六項能力如何進入戰鬥

| 能力 | 實際效果 |
|---|---|
| 根骨 | 最大氣血 `52 + 3×根骨`；2–8 對應 58–76 |
| 力道 | 每回合第一張攻擊增加 `floor(力道/2)`，整張只計一次 |
| 身法 | 每回合第一張會給防護的牌增加 `floor(身法/2)`，每回合只計一次 |
| 定力 | 開場一次換牌，上限 `1 + floor(定力/3)`；2–8 對應 1–3 張 |
| 悟性 | 不另加戰鬥傷害；≥6 的首次精修成本減至 1 心得 |
| 機緣 | 不另加掉寶或暴擊；≥6 的首次外出給提示，仍需完成原調查 |

力道、「下一張攻擊」與照隙追加等平加值，只加到整張牌的第一個有效命中，不乘上多段或敵人數。例：力道 6 時，本回合第一張未精修雙燕回鋒為 `(3+3)+3=9` 原始傷害，不是兩段都加 3。遇到敵人防護或破綻，再按每次實際命中計算。

武學與見識保留作為活動及錄取成長；本輪戰鬥不暗中再依這兩項疊加傷害。能力的精確用途應在建角回顧、角色面板與牌面預覽相符。

## 一場戰鬥的規則

1. 以該次出發鎖定的十張牌、能力、精修與種子建立牌堆，抽五張，顯示敵意圖。起手可換一次，數量由定力決定，或直接開始；被換走的牌不會立即抽回自己。
2. 玩家回合有 3 點真氣。先查看牌面與懸停預覽，再點牌施放；多名對手時選擇目標；不合法的目標或真氣不足不消耗牌與資源。回復真氣可以暫時超過 3，模型上限 20。
3. 普通出過的牌進棄牌堆；「本場除外」進除外堆。抽牌堆不足時洗入棄牌，再繼續抽取；沒有可抽牌就停止，不憑空補牌。
4. 主動結束回合時，未出的手牌全部棄掉。敵人按已顯示的意圖依序行動，自己的防護先吸收傷害。沒有反應按鍵或思考時限。
5. 下一己方回合將剩餘防護清零、真氣重置為 3、抽五張，重置首張攻擊／防護加成。未用的下一張攻擊加成也清除。
6. 敵人全退場為勝；自己氣血歸零為敗。模型的 200 回合上限會以認輸收束，避免無限拖延，並非預期正常對戰長度。

虛弱令敵人每段攻擊變為 `floor(原傷害×0.75)`；破綻令敵人每次承受傷害變為 `floor(原傷害×1.5)`，之後才扣敵防護。兩種狀態都在該敵人行動後減一回合。敵防護在它下次行動開始時清除，再按本次防守意圖建立，因此可能保留到下一個玩家回合。

回復藥不是牌：每回合最多用一份、回復 20 氣血、不超過上限，氣血全滿不消耗。藥物使用量在活動成功／撤退時由行程層統一結算；同次重試恢復出發藥物額度，不額外扣時間。

## 敵人、意圖與考核

| 遭遇 | 敵人與氣血 |
|---|---|
| 劍坪練習 `practice` | 短刀模板 28 |
| 同門對練 `spar` | 短刀模板 44 |
| 溪谷 `grove` | 短刀客 30、長兵客 26 |
| 古道 `ridge` | 短刀客 36、長兵客 34 |
| 考核 `exam` | 教頭 `96 - 6×支援`；支援 0–3，即 96／90／84／78 |

考核支援為 `min(3, floor(成功完成的不同活動數/3))`，出發時固定。人物關係與守約仍參與錄取判斷，不把降低頭目氣血當成唯一人情收益。

| 對手 | 可預測循環 | 閱讀重點 |
|---|---|---|
| 短刀客 | 近身劈擊 7 → 收刀防守 4 防護 → 蓄勢重斬 10；練習改為 5／8 傷害 | 防守回合可準備資源，重斬前值得保留防護 |
| 長兵客 | 連刺 4×2 → 架槍 5 防護 → 突刺 9 | 注意每段數值與段數；兩敵遭遇中的長兵初始位置為循環第二步，先防守 |
| 考核教頭 | 照面一劍 9 → 沉肩 7 防護 → 連環三試 4×3 → 破勢重劍 14 | 剩餘氣血 ≤一半時進入二式，每段攻擊 +2、防護 +2；意圖即時更新 |

意圖不是模糊的「準備攻擊」：畫面提供當前傷害、段數或防護，虛弱修正後顯示值應與結算一致。教頭跨過半血門檻時，本回合已展示的意圖也會更新，出牌預覽與結果必須讓玩家看見變化。

## 暫停、存讀、重試與結算

純模型不依現實秒數推進。保存完整手牌、抽牌順序、棄牌、除外、真氣、防護、各次使用旗標、敵狀態及精確隨機狀態，讀取後下一次抽牌須相同。UI 選中牌、目標與牌頁可另存顯示資料，但不能代替模型。

同次重試從鎖定出發資料重建，保留種子與起始牌組；重新安排一個新活動才是新的種子。非法快照明確拒絕，不默默重開。出招演出只展示模型已決定的事件，不藉動畫再加傷害，也不重發完成回報。

勝負回報交給行程層的活動 token 處理；後者才扣藥、加武學、心得、卡牌與信任。退出畫面、重複 callback、讀檔重播收尾都不能再領一次。

## 本輪要驗證的取捨

模型測試需覆蓋十八種牌的兩種等級、單體／群體／多段加成只計一次、狀態與防護先後、抽空重洗、除外、同種複本守恆、起手換牌、五模式與精確 JSON 恢復。UI／瀏覽器另測真實點擊與預覽，不用直接改敵氣血假裝卡牌流程已玩過。

真人試玩優先看：是否先讀敵意圖、能否預測費用和結果、是否理解新招式需配入、是否願意為精修放棄另一個活動。起始牌組可通關只是可行性下限，不能據此宣稱十八張牌的差異、平衡與教學已經完成。詳見 [PLAYTEST_PROTOCOL.md](PLAYTEST_PROTOCOL.md)。
