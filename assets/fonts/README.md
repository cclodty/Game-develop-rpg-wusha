# Bundled fonts

Jianghu Sans and Jianghu Serif are Traditional Chinese (TC) subsets of the installed Noto Sans CJK and Noto Serif CJK Regular fonts. They retain Latin characters, common punctuation/symbols, CJK Extension A and the Unified Ideographs block. The names were changed to distinguish these game bundles from the upstream fonts. Glyph shapes are unchanged.

Upstream: https://github.com/notofonts/noto-cjk
License: SIL Open Font License 1.1; see LICENSE-NOTO.txt (font license section).
Source package: Debian fonts-noto-cjk, source files NotoSansCJK-Regular.ttc and NotoSerifCJK-Regular.ttc, Traditional Chinese face. FontTools was used to extract/subset; no font network download was needed.
