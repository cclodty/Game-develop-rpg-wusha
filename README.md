# 山河行：Windows 遊戲下載

繁體中文 Q 版武俠 RPG，包含 Dialogue Manager 清河渡開場劇本。

## 下載與開始遊玩

[下載遊戲包（約 49 MB）](https://github.com/cclodty/Game-develop-rpg-wusha/raw/refs/heads/playable-download/shanhexing-web.zip)

1. 下載 `shanhexing-web.zip`，按右鍵選「全部解壓縮」。
2. 進入解壓後的 `shanhexing-web` 資料夾，雙擊 `Play-Windows.cmd`。
3. 遊戲會在預設瀏覽器開啟；遊玩時保留啟動視窗，結束後關閉即可。

不需要安裝 Godot 或 Python。若瀏覽器未自動開啟，可在啟動視窗顯示遊戲已準備好後，開啟 `http://127.0.0.1:8060/`。

## 操作

按「初入江湖」建立角色，再於清河渡按「四處走走」開始劇情。Enter／空白鍵繼續對話，數字鍵選擇回答；每句自動存檔。

包內附素材與開源依賴授權。存檔保存在自己的瀏覽器；此包不含玩家存檔、憑證或雲端設定。下載檔的 SHA-256 列於 `SHA256SUMS.txt`。

已在 Linux PowerShell 與 Chromium 驗證遊戲載入、創角、劇本及存檔續讀；Windows 雙擊與預設瀏覽器啟動尚未在使用者電腦實測。

此分支用於交付遊戲包，未包含專案原始碼。
