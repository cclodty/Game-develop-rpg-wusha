## 開啟圖鑑

1. 下載 ZIP，按「全部解壓縮」。
2. 進入 `wuxia-item-library` 資料夾。
3. 雙擊 `index.html`，用瀏覽器查看與搜尋；不需要安裝遊戲引擎、Python 或啟動伺服器。

GitHub 檔案頁只顯示 HTML 原始碼；下載並解壓後才可使用互動圖鑑。
