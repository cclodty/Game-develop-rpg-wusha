# 江湖未遠 · 手繪 GAL 網頁版

這是可操作的原生 HTML／CSS／JavaScript 試玩版，使用已確認的半身立繪、紙張飾框、文楷字體及人物專屬牌圖。它共用 `chapter/model.js` 的事件、日期、研習與三人戰鬥規則，不需要安裝 Godot。

## 開始遊玩

1. 將 `jianghu-gal-web.zip` **全部解壓縮**，保留資料夾結構。
2. 用桌面版 Chrome 或 Edge 開啟根目錄的 `index.html`。Windows 也可雙擊 `Play-Windows.cmd`。
3. 輸入名字，按「初到渡口」。點擊正文先顯示全文，再次點擊才繼續。
4. 設定可調整四種字速、句間停留及減少動態。自動閱讀遇到選項會停下。

若本機瀏覽器限制直接讀檔，可在解壓縮後的根目錄執行 `python -m http.server 8091 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8091/`。素材、字體與程式都包含在包內，沒有外部 CDN 或帳號需求。

開發工作區的入口為 `web/index.html`，從專案根目錄啟動相同伺服器後，網址為 `http://127.0.0.1:8091/web/`。雲端工作區的 localhost 只屬於該機器，不是對外分享連結。

## 本版範圍

- GAL 逐句閱讀、人物表情與名字框、明確的回應選項、回看及獨立閱讀設定。
- 四個區域入口、14 個事件、三種章末結果。查看場景和閱讀不耗時，承諾活動前顯示代價。
- 行囊顯示實際盤纏、傷藥與取得的線索。銀匙與手札沿用開場設定；沒有另造十二項樣板物品或出售規則。
- 三人按速度出牌，各有手牌、真氣與勢。同伴預設自動，可以暫停與接管；主角背影與敵方全身圖用於交手構圖。
- 三門武學、各兩層；保存最佳成績，重複研習自動沿用。新招式須自行配入牌組。
- 三個手動存檔、自動保存、上一份自動備份、JSON 匯出及匯入。刷新可保留閱讀位置、戰鬥換牌和研習順序。

網頁版存檔使用 `jianghu-gal-web-v1:*`；閱讀偏好使用 `jianghu-gal-web-reading-v1`。不會自動覆寫舊 HTML 章節或 Godot 的存檔。可以主動匯入舊章節 JSON，舊檔沒有逐句閱讀紀錄時會返回當時場景。

存檔屬於目前瀏覽器和網址，不會雲端同步。移動資料夾、換瀏覽器或清除網站資料前，請先從存讀頁下載備份。

## 已知界線

本版仍是小說改編試玩，正式原稿核對、創角問答與第二區域尚未完成。河倉與渡口共用背景的不同取景；敵方使用既有模板，杜蘅專屬牌面及同伴背影待補。未製作自由行走地圖、完整語音或新音效。

驗收尺寸為桌面橫向 1440×900 與 960×600；其他尺寸按比例留邊。手機直向、Safari、Windows／Edge 實機另待驗證。受管 Chromium 若禁止 `file://`，會在驗證紀錄註明；不能把 HTTP 測試宣稱為直接讀檔測試。

## 素材與驗證

所有文字使用霞鶩文楷 TC Medium 1.530，字體原檔與 SIL OFL 1.1 授權在 `assets/fonts/`。生成圖維持原檔，瀏覽器以 SVG 取格；來源見各 `provenance.json`。

執行 `python tools/test_native_web.py` 驗證真實滑鼠、鍵盤及完整章節流程；模型回歸為 `node tests/test_ferry.cjs` 和 `node tests/test_card_art.cjs`。檢查紀錄與實際截圖在 `artifacts/native-web/`。打包指令為 `python tools/package_native_web.py`。
