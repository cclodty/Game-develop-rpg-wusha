## Description
宋懷晴的青緞劍穗，穗頭纏一圈紅線。第4章因渡船濺水拆下晾窗邊，睡前往裡挪過。第8章穗尾沾泥血。
## History
懷晴早晨忘了收，正確所有人是她；第8章姚令儀從方素秋床腳外側拾出，拒讓懷晴拿回。後交核問者留證，第21章裝木盒對證，未歸還；目前無具名角色持有，故省略 owner。姚承認前晚窗取、交給受雇者，與石三床腳小包及行程紙互證。
## Function
物件本身不能證明懷晴何時到場、是否殺人；第21章取放過程被人證供詞核實，成為主動栽贓的證據之一。

## Current State
第37章已回1447初遇日上午，以上封盒對證屬第一輪。陳記得姚前夜取穗，尚未在本輪進茶院找到；宋尚不知它被用於栽贓。不可寫成仍在1452證物盒。

第39章陳在床腳先發現，叫宋與郎中看清原位，乾紙攏放公開桌面待查。未交姚、未憑它指宋殺人；宋確認昨夜窗上今晨未收，仍未親見誰拿去。

第49章案件核實取放與主動栽贓，勘驗留樣後歸宋，收布囊未立刻繫劍。
