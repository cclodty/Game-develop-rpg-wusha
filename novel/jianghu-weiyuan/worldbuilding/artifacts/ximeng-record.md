## Description
許循病者殘頁及數份抄本比對的虛構古抄，非成書晚於明代的現代典籍。前後缺葉，有還息圖、中心留白，尚不知還到何處。
## 第一輪第25章狀態
第25章個體還息令附著於末勢的異常鬆開，修帆青年多月睡穩可工。許誠實記反覆案例與實傷不隨術癒，不知大規模效果，未在正文證明全書真實原理。

## Current State
