## Description
比尋常門鑰匙細，柄較長，一端有深淺不一的齒，一端為扁環；環上纏枝狀細紋部分磨平。環柄接處有會掛住皮膚的裂口。無刻姓或數目。首次見於第二章。
## Function
第31章首次對已存在的異常門隙發聲，近處對上無形凹口能開光縫、遠離能收。不是任何普通門均可開，未使病者痊癒。持匙者可見親歷記憶殘影，旁觀者所見不同；無復活或許願證據，尚未知交易。第19章確認與裴家殘匣拆下的鎖孔不合。裴要求只詢問補環價格，不改匙齒，回來親自決定，現已無法親取。
## History
裴守成家中舊物。第二章託陳天佑保管三日，修補詢價是託付原因。所有權仍屬裴；owner 記錄當前保管人。
## Current State
第47章：本輪女首次詳核寄匙與匣文，既有薄異隙可開灰檻；男看34親歷合縫布，女只灰檻水光，未授權讀他記憶便未見人。無新交易或治病，女約不獨試。匙、寄放字據、拓紙各自包裹仍行囊內袋，未改衣內袋。

第37章回返後：只有一枚，恢復在1447年舊行囊內袋、寄放字據旁，環未修。1452衣內小袋未隨穿越，門後交易已在陳記憶中生效，不因匙復舊就取消。以下為第一輪保管歷史。

第19章兩人確認裴死訊；陳向查問者交代寄放，與先前報備字據相核，仍保管待親屬或正式核問，不據為自己財物。匣與銅片留作案物，僅拓紙隨陳。匙仍裂、未改未修，青布新乾紙包、裂環朝內。

第31章試門後改放衣內新縫貼身小袋，仍裹好，與字據及拓紙分存；陳宋許共同核查，陳宋約定試探前知會對方。先前行囊保管紀錄：第9章袋滑落，第10章拾回後宋代背，第12章縫袋時宋已知寄放來歷。參見 [陳天佑](../../characters/chen-tianyou.md)。

第58章事件解決後於早存後門灰隙，男允共享親歷、女經准同持柄，先短段鬆手退再看五年立約印痕。無新交易無跨檻，非讓女承原先記憶身份、非未知內心。閉門後匙分包仍由男保管。

第60章最終：宋將匙與裴字據交周核記，沈暫保、周續尋親，已告異隙危險。owner只記保管，不將所有權改為沈。沒有新借命、未改齒未修環。
