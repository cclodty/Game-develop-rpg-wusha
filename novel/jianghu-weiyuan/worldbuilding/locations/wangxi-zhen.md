# 望溪鎮

## Description

徽州山間的虛構小鎮，溪水穿過東側，山路與驛路在鎮外相接。石板街、貨棚、藥鋪、豆腐房與小劍塾構成主角的日常。下雨時貨車帶來黃泥，溪灣外的新磨坊須沿矮壩繞行。

## History

正統十二年開篇；不指定為真實歷史縣城。民間信腳在官驛周邊接商旅託物，並不等同官驛職員。

## Culture & Customs

熟客之間常口頭託付，交件與回話須核對。幫忙可以計酬，守信不要求窮人無償承擔一切。

## Notable Features

東橋兩端有多戶李家；舊磨坊改作豆腐房，磨與老人搬至溪上游的新水口。陶半夏藥鋪、周望山貨棚與沈照嶺劍塾在鎮街上。第一章借來的破邊斗笠須歸還。

## Current State

第1章：秋末落雨，暮前雨歇；天佑左肩因偏擔痠痛、鞋帶斷後以麻繩代繫，未受嚴重傷。陌生旅人扭傷右腳，到貨棚求修木匣。
