## Description
望溪鄰鎮丁記與沿河貨棧、轉貨場合稱的旅行範圍。不是同一碼頭，陸路後接能行小舟的河段，再與大船轉貨；各處旅行留時間，不讓大船航入每條溪流。具體坊鎮為小說虛構，不宣稱地方水文已考據。
## Current State
第15章接傷者的承運名烏篷行，與茶院命案日領匣底單相接。原包藥紙封在丁記、原領匣底單在茶行；主角持描紙與回話。烏篷行退租舊屋，公開留下一處下游收貨地址，尚無主使證據。
